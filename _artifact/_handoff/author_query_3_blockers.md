# 원고 확인 요청 — 3개 항목

**대상 원고**: 《인간과 봇이 협력하는 AX경영》 (박원우, 2026-07-05판, 154쪽)
**요청 사유**: 원고를 개념 단위로 구조화하는 작업 중, **저자의 판단이 있어야만 확정 가능한 3개 지점**이 확인되었습니다.
**성격**: 오탈자 지적이 아니라, **장(章) 간 서술이 서로 다르거나 라벨과 내용이 어긋나는 지점**입니다. 어느 쪽이 정본인지는 저자만 정할 수 있어 임의로 정하지 않고 그대로 두었습니다.
**회신 방법**: 각 항목의 **「확인 요청」** 아래 선택지에 표시해 주시거나, 자유롭게 의견을 적어주시면 됩니다.

## 항목 1. LLM 체계도의 **4층**에 해당하는 것

### 현재 원고 상태

**1장** (p.15 부근)
> "이 체계도에서 1~2층은 DX의 영역이고, 1~4층이 AX의 영역이다. **현재 4층이 이미 세상에 나와 있다.** … 사람들은 이를 LLM이라 칭하는데, 여기서는 비교를 위하여 이를 **'제 1의 LLM'**이라고 하겠다."

→ 4층 = **제1의 LLM**

**8장** (AI의 예측지능)
> "앞서 1장에서 LLM의 체계도라 칭하면서 그림의 내용 중 1~4층을 설명하였는데, **여기서는 5층이 추가되었다.**"
> "AI 예측지능 체계에서 설명할 중심 내용은 3과 4층이다. **4층의 월드 모델(world model)은 이 예측 능력의 기술적 기반**인데…"

→ 4층 = **월드 모델**

### 확인이 필요한 이유

1. 8장이 **"1장과 같은 그림에 5층만 추가"** 라고 명시했으므로, 두 곳의 4층은 같아야 합니다.
2. 그런데 8장 자신이 월드 모델에 대해 이렇게 씁니다:
   > "물론 아직 일반화 된 것은 아니고, **극소수 big tech이 검증하는 단계**에 있다."

   이는 1장이 4층에 부여한 성격(**"이미 세상에 나와 있다"**)과 반대입니다.

즉 **"이미 나와 있는 것"** 과 **"아직 검증 단계인 것"** 이 같은 4층에 놓여 있습니다.

### 확인 요청

- [ ] **(가)** 4층 = 제1의 LLM 이 정본. 8장의 "4층의 월드 모델"을 다른 층(예: 5층)으로 수정
- [ ] **(나)** 4층 = 월드 모델 이 정본. 1장의 층 번호를 조정
- [ ] **(다)** 두 그림은 애초에 다른 체계도. 8장의 "같은 그림" 서술을 수정
- [ ] **(라)** 기타 — 의견:

## 항목 2. **「역할」** 이라는 용어가 두 가지 뜻으로 쓰임

### 현재 원고 상태

원고에서 **「역할」** 이 서로 다른 두 개념을 가리킵니다.

| | 위치 | 뜻 |
|---|---|---|
| **A** | **3장** — AI 시대 역할론 | **기여의 위치**로서의 역할 ("역할은 직함이 아니라 기여의 위치") |
| **B** | **7장** — 공통 컨텍스트의 구성요소 | 공통 컨텍스트를 이루는 **6개 요소 중 하나**로서의 역할 (목적·기준·**역할**·출처·형식·피드백) |

### 확인이 필요한 이유

- 두 곳 모두 **수식어 없이 「역할」** 로만 표기되어 있습니다.
- 층위가 다릅니다 — A는 **개념 정의(존재론적)**, B는 **운영 항목(실무적)**.
- 원고에서 두 서술이 서로를 언급하지 않아, 독자가 같은 것으로 오해할 여지가 있습니다.

※ 참고: 두 개념은 출처 위치·문맥·정의가 모두 달라 **중복이 아님**을 확인했습니다. 저자께서 같은 단어를 의도적으로 두 뜻으로 쓰신 것인지, 구분이 필요한지만 판단해 주시면 됩니다.

### 확인 요청

- [ ] **(가)** 현행 유지 — 문맥으로 구분되므로 그대로 둠
- [ ] **(나)** 3장의 「역할」에 수식어 추가 (예: 기여 위치로서의 역할) — 제안 표기:
- [ ] **(다)** 7장의 「역할」에 수식어 추가 (예: 컨텍스트 역할 항목) — 제안 표기:
- [ ] **(라)** 양쪽 모두 수식어 추가 — 제안 표기:

## 항목 3. **포용전환 ESG 「12지표」** — 실제 열거는 **13개**

### 현재 원고 상태

**8장** (p.140 부근)
> "다음 지표(**가칭 포용전환 ESG 12지표**)는 조직이 AI 전환을 책임 있게 운영하는지 확인하기 위한 기본 항목이다."

이어지는 열거 항목:

| # | 지표 | | # | 지표 |
|---|---|---|---|---|
| 1 | AI 접근성 | | 8 | 감사 기록 |
| 2 | AI 교육 | | 9 | 책임구조 |
| 3 | AI 활용 역량 | | 10 | 성과 공유 |
| 4 | 노동 전환 | | 11 | 맥락자본 |
| 5 | 인간 판단권 | | 12 | 책임운영체계 |
| 6 | 설명 가능성 | | **13** | **환경 책임** |
| 7 | 이의제기권 | | | |

→ 라벨은 **12**, 실제 열거는 **13**개입니다. (원고 전체에서 「12지표」는 이곳에 단 한 번 등장합니다.)

### 확인이 필요한 이유

작업 과정에서 임의로 정할 수 없었습니다.
- **13으로 이름을 바꾸면** → 저자께서 붙이신 명칭을 바꾸는 것
- **항목 하나를 빼면** → 저자께서 쓰신 내용을 삭제하는 것

### 📌 함께 확인 부탁드릴 사항 (레이아웃)

7번(이의제기권)과 8번(감사 기록) **사이에 목록과 무관한 문단이 끼어** 있습니다:

> "표준이다. EU AI Act는 위험 기반 AI 규칙을 제시하며, UNESCO와 OECD는 인간 권리, 투명성, 인간 감독, 책임성을 강조한다."

문장이 **"표준이다."** 로 시작하는 점으로 보아 **앞 문단의 뒷부분이 잘려 들어온 것**으로 보입니다. 원본 편집 과정의 문제일 수 있으니, **원본 PDF에서 이 부분의 레이아웃도 함께 확인**해 주시면 좋겠습니다. (지표 개수가 어긋난 원인이 여기에 있을 가능성도 있습니다.)

### 확인 요청

- [ ] **(가)** 13개가 맞음 → 명칭을 **「13지표」** 로 수정
- [ ] **(나)** 12개가 맞음 → 제외할 항목:
- [ ] **(다)** 「가칭」이므로 개수를 명시하지 않는 명칭으로 변경 — 제안 표기:
- [ ] **(라)** 기타 — 의견:

**레이아웃 관련**
- [ ] 끼어든 문단은 편집 오류가 맞음 → 원위치 확인 필요
- [ ] 의도된 서술임
