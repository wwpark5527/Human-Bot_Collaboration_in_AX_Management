# Tool User — Goal

The goal is to identify whether a member remains at the Tool User stage of the AI Utilization (AIU) ladder, an AI-usage stage centered on asking an LLM questions and copying results, using AI like a search engine, and to design the transition path to the Collaborative User stage.

## Objectives
- Confirm whether the member's AI usage stops at the question-and-copy pattern.
- Determine whether the same result could be produced even without AI, and thereby discriminate whether the Tool User stage applies.
- Measure AI-usage frequency, number of questions, and the degree to which generated results are used as indicators.
- Take the Tool User identification result as the reference point for the Collaborative User transition plan.

## Success Criteria
The Tool User stage is determined when the same result could be produced even without AI, that is, when AI dependence is low and indicators of a simple question-and-copy pattern are confirmed.
