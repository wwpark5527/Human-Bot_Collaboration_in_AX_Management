# Level 3 Planner/Strategist — Goal

The goal is for the Planner/Strategist level in the bot hierarchy to decompose higher goals accurately into executable sub-tasks so that the lower Specialist/Executor and Tool/Reactive Agent can execute them immediately.

## Objectives
- Clearly set the goal given by the organization or by a higher agent.
- Decompose the set goal into executable sub-tasks (subgoals).
- Structure the decomposed tasks in a form that can be allocated to agents at the appropriate lower levels (Level 1-2).

## Success Criteria
The goal is judged achieved when a bot at the Planner/Strategist level actually performs the function of setting the higher goal and decomposing it into executable sub-tasks.
