# Criterion — Goal

The goal is to unify the organization's standard of judgment for what counts as a good result, so that AI does not answer the same request by a different standard each time.

## Objectives
- Set down in writing the organization's standard of judgment for what counts as a good result.
- Register the criterion in the common context so that AI shares the organization's purpose, language, and standards of judgment.
- Prevent criterion inconsistency, in which a different standard is applied to the same request each time.

## Success Criteria
Success is judged when the same standard of judgment is applied to the same request rather than answering by a different standard each time.
