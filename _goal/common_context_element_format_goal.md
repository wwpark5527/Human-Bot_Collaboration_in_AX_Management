# Format — Goal

The goal is to standardize the structure of outputs such as reports, proposals, training materials, and record forms, so that they are not made in a different format by each person, each department, and each tool.

## Objectives
- Define a standard structure for each output type (reports, proposals, training materials, record forms).
- Register the format so that the standards of the common context come down into the actual structure of outputs.
- Standardize outputs into a format that allows review, comparison, approval, and reuse.

## Success Criteria
Success is judged when outputs are not made in a different format by each person, each department, and each tool, and are in a format that allows review, comparison, approval, and reuse.
