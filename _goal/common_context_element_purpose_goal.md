# Purpose — Goal

The goal is to specify in advance, in the organization's language, why the organization uses AI, so that AI does not generate answers without direction.

## Objectives
- Set down in writing, in the organization's own language, the reason the organization uses AI.
- Provide a pre-defined purpose standard so that 'why this work is done' does not have to be guessed each time for every individual task assigned to AI.
- Settle the purpose item, which inevitably differs from organization to organization, as distinct from the general interpretation of a general-purpose AI.

## Success Criteria
Success is judged when, for the work assigned to AI, 'why this work is done' is defined in advance in the organization's language.
