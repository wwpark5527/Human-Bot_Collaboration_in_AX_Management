# AH + B (intelligent division of labor) — Goal

The goal is to identify the AH + B cooperation type in which an augmented human (AH) orchestrates multiple bots (B), and to stably realize the strategy (human)-execution (bots) division-of-labor structure through building a multi-agent environment, human-in-the-loop design, and role-based agent design.

## Objectives
- Identify the AH + B type in which, in a state where the human is augmented but the bots are not, one AH directs many Bs.
- Design and operate a division-of-labor structure in which the human is responsible for formulating strategy and the bots for execution.
- Secure the stability of the intelligent division of labor through building a multi-agent environment, human-in-the-loop design, and role-based agent design.

## Success Criteria
The goal is judged to be achieved when one augmented human orchestrates multiple bots in a strategy-execution configuration, and a multi-agent environment, human-in-the-loop, and role-based agent design are actually in place so that the division of labor proceeds without error.
