# Operator — Goal

The goal is to keep deliverables operating continuously. Through deployment, monitoring, and maintenance, the deliverable is managed so that it does not stop at a one-time result but keeps operating continuously.

## Objectives
- Deploy the validated deliverable.
- Monitor the operating status of the deliverable after deployment.
- Guarantee continuous operation by performing maintenance when problems occur.

## Success Criteria
The goal is judged to be achieved when a state in which the deliverable does not stop at a one-time result but keeps operating continuously (continuity) has been confirmed.
