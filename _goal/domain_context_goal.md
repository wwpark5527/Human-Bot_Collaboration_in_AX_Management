# Domain Context — Goal

The goal is to make the general standard called common context concrete to fit a particular work area, and thereby to be equipped with an executable structure in which humans and AI can actually work together in that work area.

## Objectives
- Clearly distinguish the relationship between common context (the standard of work criteria) and domain context (making it concrete by unit of work).
- Reconstitute common context into a form actually applicable for each particular work area.
- Connect smoothly, on the basis of domain context, to the stages of skill derivation and on-site execution.

## Success Criteria
The goal is determined to have been achieved when common context has been made concrete into an executable structure fitting a particular work area (domain context), and a state has been reached in which humans and AI can actually collaborate in that work area.
