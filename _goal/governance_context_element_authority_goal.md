# Authority — Goal

The goal is to clearly set the scope of materials and tools AI can access, so that AI runs without authority confusion across the entire network environment.

## Objectives
- Define, per context, the scope of materials and tools AI can access.
- Manage the access and execution scope by mapping it to international standards such as ISO/IEC 42001 role/access control, NIST AI RMF Govern, and EU AI Act human oversight (Article 14).
- Prevent "authority confusion," in which it becomes unclear which AI can access which materials and tools.

## Success Criteria
Success is determined when which context can access which materials and tools is clearly judged and the access and execution scope is being managed.
