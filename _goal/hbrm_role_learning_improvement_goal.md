# Learning and Improvement Management — Goal

The goal is, after the authority, verification, approval, recording, and responsibility structures have been completed through governance linkage, to accumulate the feedback and errors that arose in actual operation into organizational memory and thereby create a system in which HBRM improves itself.

## Objectives
- Collect, without omission, the achievements and errors that arose in the collaboration process of humans and bots.
- Convert the collected feedback and errors into memory (records) that the organization can reuse.
- Feed the accumulated organizational memory back into role-balance diagnosis and the improvement of HBRM operation.

## Success Criteria
The goal is judged to be achieved when feedback and errors are accumulated into organizational memory without omission and that memory is used to improve the next HBRM operation.
