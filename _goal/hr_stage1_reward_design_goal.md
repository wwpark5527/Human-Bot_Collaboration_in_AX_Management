# Stage 1 (Reward Design) — Goal

The goal is to embed human respect into the bot's reward function itself, and thereby to prevent the mistaken design in which the bot optimizes task performance alone and as a result harms humans.

## Objectives
- Design the reward function so that it reflects not only task performance but also human satisfaction.
- Design the reward function so that it reflects human-harm risk as a deduction factor.
- Design the reward function so that it includes a penalty for norm violation.
- As the first stage of the five-stage architecture for implementing human respect, lay the foundation for the subsequent stages (mandatory rules and so on).

## Success Criteria
The goal is judged to be achieved when it is confirmed that the reward function is actually composed with the structure of task performance + human satisfaction – human-harm risk – norm-violation penalty.
