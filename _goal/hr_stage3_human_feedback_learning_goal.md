# Stage 3 (Human Feedback Learning) — Goal

The goal is to have the bot learn the subtle social context that hard rules alone cannot easily address, by using RLHF/RLAIF to accumulate learning data on whether behavior respects humans.

## Objectives
- Continuously accumulate feedback data on "this behavior is human respect / is not."
- Train the bot so that desirable behavior such as an honest answer is allowed.
- Train the bot so that behavior that distorts or manipulates the process is not allowed.
- Complementarily train the subtle social context that the hard rules (Stage 2) cannot handle.

## Success Criteria
The goal is judged to be achieved when it is confirmed that the subtle contextual distinction—an honest answer is allowed, while process/manipulation is not—is actually reflected through the learning data.
