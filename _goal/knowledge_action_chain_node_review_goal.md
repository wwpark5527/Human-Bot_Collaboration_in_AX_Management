# review — Goal

The goal is to examine whether the results execution has produced match the organizational standards, so that execution does not end without verification.

## Objectives
- Confirm whether the result matches the facts.
- Confirm whether the result matches the organizational standards and whether authority was not exceeded.
- Have a person confirm accountability so that execution does not end without verification.

## Success Criteria
Whether the result matches the facts, whether it matches the organizational standards, whether authority was not exceeded, whether a person confirmed accountability — success is determined when all four are confirmed and only results that pass review become organizational standards.
