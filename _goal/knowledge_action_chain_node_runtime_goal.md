# runtime (SkillRuntime) — Goal

The goal is to complete a skill into an execution structure that works in real tasks.

## Objectives
- Define explicitly the skill's input, materials, tools, prohibitions, result format, review approver, and record location.
- Guarantee that only when this structure is defined does a skill go beyond the document level and work in real tasks.
- Convert the skill into an actual execution structure through the SkillRuntime.

## Success Criteria
Success is determined when all seven items — input, materials used, tools used, prohibitions, result format, reviewer and approver, record location — are defined so that the skill can work in real tasks.
