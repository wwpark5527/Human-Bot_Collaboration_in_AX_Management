# Structural-Distance Measurement — Goal

The goal is to show how much the current concept structure differs from the target structure, so that one can confirm not only what one does not know but also what one knows incorrectly.

## Objectives
- Compare the current concept structure with the target structure and identify missing concepts, incorrect connections, and unnecessary connections.
- Produce the structural-distance value in a way where the more of these three elements there are, the greater the distance.
- By identifying missing concepts and misconceptions separately, reveal together what one does not know and what one knows incorrectly.

## Success Criteria
Success is determined when missing concepts and misconceptions are identified and the structural-distance value between the current concept structure and the target structure is produced.
