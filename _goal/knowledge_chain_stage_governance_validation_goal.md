# Governance Validation — Goal

The goal is to make the referenced context and the response to be generated pass the organization's authority, security, verification, and approval standards, and thereby make verification and accountability tracing possible.

## Objectives
- Check the interpretation context produced in the organizational context reference stage and the response to be generated against the authority, security, verification, and approval standards.
- Resolve the existing LLM's defect that "verification/accountability tracing is difficult."
- Block response candidates that do not pass the standards, and pass on to the next stage (response generation) only those response candidates that pass.

## Success Criteria
It is judged a success when verification and accountability tracing are possible and the existing LLM's verification/accountability-tracing defect has been resolved.
