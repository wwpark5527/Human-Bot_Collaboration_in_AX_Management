# Re-reflection into Organizational Knowledge — Goal

The goal is to return the recorded result back into the organization's knowledge and standards, so that knowledge becomes not "scattered responses" but a system that is connected, verified, and evolves within the organization.

## Objectives
- Connect the traceable record (grounds, process, version) left in the result recording stage with the organization's existing knowledge and standards.
- Verify and evolve the connected knowledge, making it a system in which knowledge is not scattered but accumulated within the organization.
- Have the result absorbed into organizational knowledge so that it actually changes the standard for the next judgment.

## Success Criteria
It is judged a success when the result is absorbed into organizational knowledge and changes the standard for the next judgment.
