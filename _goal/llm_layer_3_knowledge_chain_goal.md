# Layer 3 (knowledge chain based on common & governance context) — Goal

The goal is to determine whether a knowledge chain (layer 3) based on common context and governance context has been formed within the organization, and to secure it as a core component of the organizational AX OS.

## Objectives
- Identify whether information inside the organization is being converted into knowledge through a knowledge chain based on common context and governance context.
- Recognize the failure that occurs when only layer 4 (an external LLM) is introduced while layer 3 is insufficient (remaining at a multitude of personal AX efforts).
- Embed layer 3 in the organizational AX OS and put in place the conditions for securing synergy when an external LLM is connected.

## Success Criteria
The goal is judged achieved when a knowledge chain based on common and governance context has been formed inside the organization, information is converted into knowledge, and as a result the state has been reached in which synergy arises upon connecting an external LLM (layer 4).
