# Context Builder — Goal

On the premise that when context is insufficient AI results become generic and superficial and do not fit the organization's actual work, the goal is for AX talent to build sufficiently the work environment and context in which AI can work.

## Objectives
- Clearly define the work purpose and the target user.
- Set the organizational standards and the usable data scope.
- Determine the prohibited conditions and the deliverable format in advance.
- Build the verification standards together with the performance standards.

## Success Criteria
The goal is judged to have been achieved when all eight context elements — work purpose, target user, organizational standards, data scope, prohibited conditions, deliverable format, verification standards, and performance standards — have been built and AI results are produced to fit the organization's actual work.
