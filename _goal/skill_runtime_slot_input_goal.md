# Input — Goal

The goal is to clearly specify in advance what a skill must receive when it is executed.

## Objectives
- Specify in advance the input required for executing the skill.
- Prevent the skill from being executed while the input remains unclear.
- As the first of the seven definition slots of SkillRuntime, form the premise of the remaining slots (material · tool · prohibition · result format · review approver · record location).

## Success Criteria
Success is determined when what the input is has been specified in advance.
