# Result Format — Goal

The goal is to clearly specify in advance what format the output of a skill's execution must take.

## Objectives
- Specify in advance a standardized format for the output of a skill's execution.
- Prevent a skill from being executed while the result format remains unclear.
- As the fifth of the seven definition slots of SkillRuntime, it takes over from the settlement of the prohibition slot and forms the premise of the reviewer/approver slot.

## Success Criteria
It is judged successful when what the result format is has been specified.
