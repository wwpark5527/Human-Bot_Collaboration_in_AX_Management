# Tool — Goal

The goal is to clearly specify in advance which tools will be used when a skill executes.

## Objectives
- Specify in advance the scope of execution means of the tools allowed for a skill's execution.
- Prevent a skill from being executed while the scope of tools remains unclear.
- As the third of the seven definition slots of SkillRuntime, it takes over from the settlement of the material slot and forms the premise of the prohibition slot.

## Success Criteria
It is judged successful when which tools will be used has been specified.
