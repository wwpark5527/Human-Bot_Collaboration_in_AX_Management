# 2. Build AI Context Capital — Goal

The goal is to organize purpose, criteria, sources, roles, formats, and verification standards for each task, and thereby accumulate as an asset the organizational context that AI will reference. As the second step of the AI Inclusive-Transformation ESG execution model (9 steps), it converts the results of step 1, impact assessment, into actual operating assets.

## Objectives
- Define the task units for which context capital will be built and set their priorities.
- Organize, for each task, the six items of purpose, criteria, sources, roles, formats, and verification standards.
- Accumulate the organized context in a form AI can reference and provide access paths to it.
- Regularly measure the context-capital build rate and the refresh cycle to prevent obsolescence.

## Success Criteria
It is judged successful when purpose, criteria, sources, roles, formats, and verification standards are organized for each task and the build rate and the refresh cycle are measured. (ESG linkage: S / G)
