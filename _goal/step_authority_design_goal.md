# 3. Authority Design — Goal

The goal is to set explicitly who can access which AI, data, and tools, and thereby fix the locus and boundaries of authority in AI operation within organizational governance. It is the third step of the AI Inclusive-Transformation ESG execution model (9 steps).

## Objectives
- Secure a list of the AI, data, and tools the organization operates and classify the sensitivity of each resource.
- Set explicitly, for each resource, the actors that can access it (roles, jobs, organizational units).
- Document the access-authority design so that the locus and boundaries of authority can be confirmed.
- Determine the procedures for granting and revoking authority so that authority is updated in line with personnel transfers and job changes.

## Success Criteria
It is judged successful when the actors permitted to access each AI, data, and tool are set and the access-authority design is documented. (ESG linkage: G)
