# AB_LEARNING_AUGMENTATION — Learning Augmentation

## Concept Definition
Learning augmentation is the augmentation dimension of an augmented bot (AB) that improves role-performance capability by using feedback and organizational memory. It is the third and last of an augmented bot's three augmentation dimensions (context, governance, learning); whereas the preceding context and governance augmentations deal with the bot's operating conditions, learning augmentation deals with capability improvement over time.

## Decision Criteria
Judged by whether feedback and organizational memory are actually used to improve role-performance capability.

## Output
Improved role-performance capability.
