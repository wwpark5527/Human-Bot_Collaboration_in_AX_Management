# AI_BASED_STRATIFICATION — AI-Based Stratification (AI Class Society / AI-Based Stratification)

## Concept Definition
An AI class society is a social structure in which differences in access to AI models, data, compute, platforms, organizational context, utilization capability, and decision authority accumulate, so that some own, direct, verify, and use AI while the majority are evaluated, controlled, replaced, and excluded by AI. This is not a simple loss of jobs but a new class structure created by the accumulation of differences in access rights, utilization capability, judgment authority, ownership, and profit-sharing around AI; the book uses "class" and "stratum" interchangeably, also writing it as AI class society / AI-based stratification.

## Decision Criteria
Judged by whether differences in access rights, utilization capability, judgment authority, ownership, and profit-sharing around AI accumulate so that the social structure splits into a minority that owns, directs, verifies, and uses and a majority that is evaluated, controlled, replaced, and excluded.

## Output
A new class structure (AI class society / AI-based stratification) — a risk state in which seven gaps (access, capability, context, judgment authority, surveillance, ownership, profit-sharing) accumulate simultaneously.

## Evidence (original quotation)
> "The risk AI brings is not a simple loss of jobs. The more fundamental risk is that, as differences in access rights, utilization capability, judgment authority, ownership, and profit-sharing around AI accumulate, a new class structure is created. An AI class society means the state in which this risk has deepened."
