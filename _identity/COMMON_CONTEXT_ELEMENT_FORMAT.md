# COMMON_CONTEXT_ELEMENT_FORMAT — Format

## Concept Definition
Format is the component of the common context that defines the structure of outputs such as reports, proposals, training materials, and record forms. It makes the standards of the common context come down into the actual structure of outputs. It is the fifth of the six elements (purpose, criterion, role, source, format, feedback) settled by the SplitSet fragmentation of `common context` (S2C-0103, `COMMON_CONTEXT`).

## Decision Criteria
Whether outputs are not made in a different format by each person, each department, and each tool (whether the format allows review, comparison, approval, and reuse).

## Output
Standardized outputs. 'Making results into a structure that can be repeated, compared, reviewed, and reused.'

## Evidence (original quotation)
> "Output format: the structure of reports, proposals, training materials, and record forms"
