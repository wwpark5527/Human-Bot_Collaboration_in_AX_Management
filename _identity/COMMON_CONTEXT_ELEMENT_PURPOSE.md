# COMMON_CONTEXT_ELEMENT_PURPOSE — Purpose

## Concept Definition
Purpose is the component of the common context that specifies why the organization uses AI. It is an item that inevitably differs from organization to organization, and it is the starting point that keeps AI from generating answers without direction. It is the first of the six elements (purpose, criterion, role, source, format, feedback) settled by the SplitSet fragmentation of `common context` (S2C-0103, `COMMON_CONTEXT`).

## Decision Criteria
Whether, for the work assigned to AI, 'why this work is done' is defined in advance in the organization's language.

## Output
A statement of the organization's own purpose for using AI (a purpose standard so that AI does not have to guess with every request).

## Evidence (original quotation)
> "Purpose: the reason the organization uses AI"
