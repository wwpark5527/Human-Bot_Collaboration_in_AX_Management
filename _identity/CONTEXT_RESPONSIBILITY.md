# CONTEXT_RESPONSIBILITY — Context Responsibility

## Concept Definition
Because AI produces generic answers without context, this is the responsibility of AX-organization talent to provide the work context so that AI works in line with the organization's purpose and standards. It is the first of the three responsibilities (context, judgment, evidence) that AX-organization talent holds when working with AI.

## Decision Criteria
Judged by whether the work purpose, target users, organizational standards, prohibited conditions, usable data, output format, verification standards, and performance standards have been provided to AI.

## Output
It produces the work context aligned with the organization's purpose and standards (the set of input conditions for AI work).
