# KNOWLEDGE_ACTION_NODE_ONTOLOGY — Knowledge-Action Chain Node Ontology (identity·goal·knowledge·method·skill·task·artifact)

## Concept Definition
The knowledge-action chain node ontology is the name for a structure in which the seven node types — identity, goal, knowledge, method, skill, task, artifact — are connected as an actual knowledge-action chain within one graph. This structure is visualized in Obsidian Graph View and is presented as a tool that shows at a glance "how the pieces of knowledge I have are connected to one another." The original text mentions four photos showing the formation flow of this ontology (in an order that starts at the top left and continues clockwise), but "omits the detailed explanation," so it explicitly specifies only the names of the seven nodes and the fact that they are connected into one graph.
