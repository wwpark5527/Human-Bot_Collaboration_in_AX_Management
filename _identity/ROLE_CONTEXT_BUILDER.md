# ROLE_CONTEXT_BUILDER — Context builder

## Concept Definition
This is the role in which AX-organization talent composes the work environment and context so that AI can do its work. It is the second of the eight roles of AX-organization talent. When context is lacking, AI results become generic, superficial, and unsuited to the organization's actual work, so eight context elements — from the purpose of the work through the performance criteria — must be composed.

## Decision Criteria
Have the following been composed: work purpose (why is this work being done), target user (for whom is the deliverable), organizational criteria (which internal standards must be followed), data scope (which materials may be used), prohibited conditions (what must not be done), deliverable format (in what structure the result should come out), verification criteria (how the result will be checked), and performance criteria (into what performance the result should lead).

## Output
Context that prevents generic, superficial results and fits the organization's actual work.
