# Tool User — Knowledge

## Core Knowledge
- The Tool User is the first stage of the four-stage evolution ladder (Tool User → Collaborative User → Orchestrator → Augmentation User) defined in the measurement of AI Utilization (AIU).
- Its characteristics are "asking an LLM questions, copying results, using AI like a search engine," and its indicators are AI-usage frequency, number of questions, and the degree to which generated results are used.
- The evaluation question is "Could the same result be produced even without AI?", and if that question can be answered yes, the member is regarded as being at the Tool User stage.
- The AI-utilization level means the degree of evolution in the process of moving from H0 to H1, H2, and eventually becoming an augmented human (AH), and the Tool User is the starting point of that evolution, leading to the next stage, the Collaborative User.
