# Behavior Type vs Personality Type — Knowledge

## Core Knowledge
- A team role (TR) is not an MBTI-style personality type but a behavior type exhibited by a person.
- Personality substantially influences an individual's behavior, but adults do not act solely according to their personality, and actual behavior can vary with learned individual experience and effort.
- In the twentieth century there was no concept of behavior type, so personality type, which helps in inferring it, was used; now, because the concept of behavior type and the means to measure it exist, organizational management based directly on behavior type is possible.
- By accurately diagnosing and using which behavior types each individual actually exhibits well, might exhibit, or fails to exhibit when working with others, team performance can be dramatically increased.
- This distinction is reconfirmed in footnote 44 of Chapter 6, and since there is no reason at all to consider personality type for bots, behavior type emerges as a common diagnostic axis without distinguishing humans from bots.
