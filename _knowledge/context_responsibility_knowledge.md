# Context Responsibility — Knowledge

## Core Knowledge
- Context responsibility is the first of the three responsibilities (context, judgment, evidence) that AX-organization talent holds when working with AI.
- Because AI produces generic answers without context, AX-organization talent must provide the work context so that AI works in line with the organization's purpose and standards.
- The elements included in the context: work purpose, target users, organizational standards, prohibited conditions (the meaning axis) / usable data, output format, verification standards, performance standards (the included-content axis).
