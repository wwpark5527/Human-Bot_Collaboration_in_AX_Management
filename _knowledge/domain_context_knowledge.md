# Domain Context — Knowledge

## Core Knowledge
- Domain context is one of the additional conditions of the organizational AX OS, and it is located in the right-hand column (the additional conditions) together with common context and governance context.
- If common context is the standard of work criteria, domain context is the executable structure that makes those criteria concrete to fit actual units of work.
- It is the stage of reconstituting common context into a form actually applicable so that humans and AI can work together in a particular work area.
- In GP Corp.'s AX OS it is applied to actual work in the flow 'common context structure → domain context → skill derivation → on-site execution → verification and approval → recording and feedback → context improvement'.
