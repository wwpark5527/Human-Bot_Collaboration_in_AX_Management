# Security — Knowledge

## Core Knowledge
- Security is `S2C-0424` and is the second of the seven elements (authority, security, verification, approval, record, accountability, improvement) of `governance context`(S2C-0105, `GOVERNANCE_CONTEXT`).
- The seven-element table of the governance context (lines 188-209) defines the core question of security as "which information must not be entered, shared, or generated?" and its meaning as "protection of sensitive information and confidentiality."
- One of the problems that arises when there is no governance context is "security risk: the boundary between sensitive information and externally disclosable information can collapse" (line 222).
- The international standards mapping table (lines 227-236) maps the security element to "data/asset management" in ISO/IEC 42001, "Map/Manage" in NIST, and "data governance (Article 10)" in the EU AI Act.
