# The 2nd LLM — Knowledge

## Core Knowledge
- The 'second LLM' is a model equipped with a knowledge chain based on common and governance context; it is a designation that narrowly names the knowledge chain and context of layer 3, and broadly names the sum of layers 1 through 4.
- Technically it is not an entirely new LLM but is closer to an upper architecture on top of the existing LLM, yet because of the changes in paradigm (text generation → knowledge control) and in operating entity (big tech → the individual enterprise), the validity of a generational distinction is acknowledged.
- It goes through an evolutionary process in which the enterprise lays its own rule set on top of the model made by big tech (the first LLM) and internalizes it.
- As a result it realizes an enterprise-customized AX system that resolves the problems of security and hallucination and dramatically reduces the enormous electric power and token costs that arise in the course of organizational AX.
