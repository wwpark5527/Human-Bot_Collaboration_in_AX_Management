# Layer 3 (knowledge chain based on common & governance context) — Knowledge

## Core Knowledge
- Layer 3 of the LLM architecture is the layer that turns information into the knowledge needed within an organization, and it is the place where the knowledge chain together with the common context and governance context are situated.
- For the LLM at layer 4 to be used for organizational AX, the layer-3 knowledge chain must exist, and this must be inside the OS for organizational AX.
- Even though big tech released the layer-4 LLM to the world, when layer 3 was insufficient there had been difficulty in realizing organizational AX.
- Global experts call the layer-3 knowledge chain (including the common and governance context) — narrowly layer 3, broadly layers 1–4 combined — "the second LLM."
- If one connects only to layer 4 without layer 3, a multitude of employees end up using the external LLM only at the individual level, so that both organizational synergy and security become weak.
