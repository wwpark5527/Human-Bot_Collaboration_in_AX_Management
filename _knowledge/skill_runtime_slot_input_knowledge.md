# Input — Knowledge

## Core Knowledge
- Input is `S2C-0448`, the first of the seven slots defined by `SkillRuntime` (S2C-0117, `SKILL_RUNTIME`). It is positioned after SkillRuntime itself and before material (`SKILL_RUNTIME_SLOT_MATERIAL`).
- The knowledge-action chain turns knowledge into a skill and makes that skill into an actual execution structure. What matters here is SkillRuntime, and the first item that SkillRuntime defines is the input.
- The seven items that SkillRuntime as a whole defines: input, material, tool, prohibition, result format, review and approver, record location. Only with this structure does a skill work in actual practice.
- If the input is not specified in advance, the skill cannot be executed — it is the first slot that forms the premise of the remaining six slots (material · tool · prohibition · result format · review approver · record location).
