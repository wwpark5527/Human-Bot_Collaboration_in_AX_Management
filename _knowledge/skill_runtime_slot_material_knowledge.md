# Material — Knowledge

## Core Knowledge
- Material is `S2C-0449`, the second of the seven slots defined by `SkillRuntime` (S2C-0117, `SKILL_RUNTIME`). It is positioned after input (`SKILL_RUNTIME_SLOT_INPUT`) and before tool (`SKILL_RUNTIME_SLOT_TOOL`).
- The knowledge-action chain turns knowledge into a skill and makes that skill into an actual execution structure. The second item that SkillRuntime defines is material.
- The seven items that SkillRuntime as a whole defines: input, material, tool, prohibition, result format, review and approver, record location. Only with this structure does a skill work in actual practice.
- If the scope of materials is not specified in advance, the skill will refer to arbitrary materials — as the second slot, after input and before tool, it fixes the reference scope to be used in execution.
