# Record Location — Knowledge

## Core Knowledge
- Record Location is `S2C-0454`, the last (seventh) of the seven slots defined by `SkillRuntime` (S2C-0117, `SKILL_RUNTIME`). It is positioned after reviewer/approver (`SKILL_RUNTIME_SLOT_REVIEWER_APPROVER`), and with this slot all seven items of SkillRuntime are completed.
- The knowledge-action chain turns knowledge into a skill and makes that skill into an actual execution structure. The last item that SkillRuntime defines is the record location.
- The seven items that SkillRuntime as a whole defines: input, material, tool, prohibition, result format, review and approver, record location. Only with this structure does a skill work in actual practice.
- If the record location is not specified in advance, the execution history cannot be traced — as the last slot, after reviewer/approver, it fixes the traceability of the execution process and results, and with this the definition of the seven SkillRuntime slots is completed.
