# Result Format — Knowledge

## Core Knowledge
- Result Format is `S2C-0452`, the fifth of the seven slots defined by `SkillRuntime` (S2C-0117, `SKILL_RUNTIME`). It is positioned after prohibition (`SKILL_RUNTIME_SLOT_PROHIBITION`) and before reviewer/approver (`SKILL_RUNTIME_SLOT_REVIEWER_APPROVER`).
- The knowledge-action chain turns knowledge into skills and turns those skills into actual execution structures. The fifth item that SkillRuntime defines is the result format.
- The seven items that SkillRuntime as a whole defines: input, material, tool, prohibition, result format, reviewer/approver, record location. Only with this structure does a skill work in actual work.
- If the result format is not standardized in advance, the output is difficult to compare and verify at the review and approval stage — as the fifth slot, after prohibition and before reviewer/approver, it settles the standard format of the output.
