# Social Cooperation Norm Learning — Knowledge

## Core Knowledge
- Human organizations are moved by power, trust, tacit knowledge, politics, culture, face, and emotion.
- For AI to become an organizational member, it must learn when it should speak, when it should stay silent, how it should explain, whom it should persuade, and which expressions are felt as threatening.
- AI must not simply be an intelligent system but a socially compatible system.
- The core thesis of Part 2 of Gibbins's book is that AI must be taught not only tasks but context, because one of the biggest reasons for human-AI collaboration failure is giving AI only instructions and no context.
