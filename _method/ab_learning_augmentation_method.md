# Learning Augmentation — Method

## Method / Procedure
1. Collect feedback on the results of the bot's role performance.
2. Connect organizational memory (past work records and cases) so that the bot refers to it.
3. Reflect the collected feedback and organizational memory in improving the bot's way of performing its role.
4. Confirm the improved role-performance capability.

## Criteria
If it is confirmed that feedback and organizational memory have actually been reflected in improving role-performance capability, it is judged PASS (learning augmentation confirmed); otherwise it is judged FAIL (learning augmentation not confirmed).
