# Collaboration between Augmented Humans and Augmented Bots — Method

## Method / Procedure
1. Form the common context by conveying the organization's purpose, work standards, reference materials, formats, and prohibitions.
2. Build the governance context by defining which bot can access which materials, which results require human approval, and which records must be kept.
3. The human provides the bot with purpose and standards.
4. The bot performs analysis, execution, and recording, and presents structure and possibility to the human.
5. Verify the output results against the common context and governance context standards.
6. Connect purpose, standards, materials, judgment, revision, approval, and recording, and accumulate them as organizational assets.

## Criteria
If all three conditions — sharing the same context, collaborating within an accountability structure, and dividing roles while augmenting each other — are confirmed, it is judged PASS (collaboration established); if even one is lacking, it is judged FAIL (risk of mere tool-use or an accountability vacuum).
