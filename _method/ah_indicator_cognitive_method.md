# Cognitive Augmentation (Cognitive A.) — Method

## Method / Procedure
1. Record the number of alternatives generated and the number of variables considered when the member being measured approaches a particular problem without using AI (the baseline).
2. Record the number of alternatives generated and the number of variables considered when the same member approaches the same type of problem using AI.
3. Compare thinking depth (the multi-angled quality of the analysis) and cognitive speed (the time taken to reach a judgment) under the two conditions.
4. Combine the three measures (number of alternatives generated, number of variables considered, thinking depth / cognitive speed) and judge whether cognitive augmentation has occurred.

## Criteria
If the number of alternatives generated, the number of variables considered, and thinking depth / cognitive speed have improved after the use of AI, it is judged PASS (cognitive augmentation confirmed); if they have not improved, it is judged FAIL (cognitive augmentation not confirmed).
