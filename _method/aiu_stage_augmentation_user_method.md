# Augmentation User — Method

## Method / Procedure
1. Record the levels of the member's decision quality, learning speed, and productivity before using AI (the baseline).
2. Record the same indicators after using AI.
3. Compare the subsequent levels against the baseline and confirm whether decision quality, learning speed, and productivity have actually improved.
4. On the basis of the confirmed changes, judge "After using AI, have I become a different person from my earlier self?"
5. On the basis of the judgment result, decide whether the member falls into the Augmentation User stage.

## Criteria
If improved decision quality, increased learning speed, and increased productivity are confirmed together, it is judged PASS (falls into the Augmentation User stage); if they are not confirmed, it is judged FAIL (does not fall into the Augmentation User stage, re-evaluation at the Orchestrator stage is required).
