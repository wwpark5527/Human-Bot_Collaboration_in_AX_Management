# Collaborative User — Method

## Method / Procedure
1. Tally the member's number of prompt improvements (the number of revision and re-revision repetitions against the draft).
2. Record the degree to which the member incorporates AI feedback into the deliverable.
3. Tally the number of repeated interactions between the member and AI.
4. Combine the three indicators and evaluate "Does AI expand my thinking?"
5. On the basis of the evaluation result, judge whether the member falls into the Collaborative User stage.

## Criteria
If it is judged that thinking has been expanded through repeated interaction with AI, it is judged PASS (falls into the Collaborative User stage); if it stops at simple asking and copying (the Tool User level) or has advanced to the level of work-process design (the Orchestrator level), it is judged FAIL (does not fall into the Collaborative User stage, re-evaluation at the adjacent stage is required).
