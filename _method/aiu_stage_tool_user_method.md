# Tool User — Method

## Method / Procedure
1. Tally the member's number of AI uses (per day or per week).
2. Record the member's number of AI questions and the degree to which generated results are used as they are.
3. Apply and evaluate "Could the same result be produced even without AI?" against the member.
4. Determine on the basis of the evaluation result whether the Tool User stage applies.

## Criteria
If the same result could be produced even without AI and the usage pattern is centered on question-and-copy, it is determined PASS (the Tool User stage applies); if a pattern of revising and exploring results through interaction with AI appears, it is determined FAIL (beyond the Tool User stage, re-evaluation at the Collaborative User stage required).
