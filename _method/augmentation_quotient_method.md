# Augmentation Quotient (AQ) — Method

## Method / Procedure
1. Confirm the AIU (AI Utilization) value of the target member.
2. Evaluate Role Alignment (the degree of role-centered use).
3. Evaluate Collaboration (the level of human-bot collaboration).
4. Evaluate Governance (the level of ethics/security/approval compliance).
5. Multiply the four values (AIU, Role Alignment, Collaboration, Governance) to compute AQ.
6. Pass the produced AQ value on as the input to the AHI (Augmented Human Index) measurement stage.

## Criteria
If all four components — AIU, Role Alignment, Collaboration, and Governance — are secured and AQ is produced by the product operation, it is judged PASS; if even one is missing, it is judged FAIL (re-measurement needed).
