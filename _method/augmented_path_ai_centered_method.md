# AI-Centered Path — Method

## Method / Procedure
1. Confirm whether the communication in question is a situation where speed and efficiency matter.
2. Set the path as a structure in which the human provides only the purpose and the approval criteria while the AI relays and structures (Human A ↔ AI A ↔ AI B ↔ Human B).
3. Review whether the result of the AI's processing agrees with the human's original intent.
4. If distortion of intent is found, the human re-confirms and corrects it.

## Criteria
If the AI relays and structures messages quickly and the human's intent is preserved, it is judged PASS (the AI-centered path is suitable); if processing is fast but the intent is distorted, it is judged FAIL (requires attention).
