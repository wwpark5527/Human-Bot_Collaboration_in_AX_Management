# Via-Governance Path — Method

## Method / Procedure
1. Confirm whether the communication in question belongs to a domain where accountability matters.
2. Set the message into the structure of passing through the governance context (Human A ↔ AI A ↔ governance context ↔ AI B ↔ Human B).
3. Check in order whether the criteria of authority, security, verification, approval, recording, and accountability are passed.
4. If even one of the criteria is not passed, hold the delivery of the message.

## Criteria
If the message passes all six criteria of authority, security, verification, approval, recording, and accountability, it is judged PASS (the via-governance path is satisfied); if even one is not passed, it is judged FAIL.
