# Prompt Architect — Method

## Method / Procedure
1. Identify, by type of work, the intent, context and constraints that must be conveyed to AI.
2. Design the identified elements into a structured interaction (prompt) format.
3. Document the designed interaction patterns as standards and templates.
4. Verify the results of actual application (accuracy, reduction of rework) and improve the design.

## Criteria
If a design for human-AI interaction is established and applied to actual work with a confirmed effect, it is judged PASS; if there is no design or the effect is not confirmed, it is judged FAIL.
