# Provenance Controller — Method

## Method / Procedure
1. Confirm the list of input data sources used by AI and collect provenance metadata.
2. Record the processing path of the AI output generation process (input -> processing -> output).
3. Keep the provenance and traceability records in a verifiable form.
4. Regularly check the records for omissions and errors and supplement them.

## Criteria
If records of data provenance and traceability are produced and kept in a verifiable form, it is judged PASS; if the provenance is unknown or tracing is impossible, it is judged FAIL.
