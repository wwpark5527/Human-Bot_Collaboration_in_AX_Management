# Behavior Type vs Personality Type — Method

## Method / Procedure
1. Collect self-diagnosis and observer-diagnosis data on each individual's actual exhibited behavior.
2. Diagnose with behavior-type measurement instruments, clearly distinguished from personality-type tests (MBTI and the like).
3. Organize the results by distinguishing the behavior types that are exhibited, that might be exhibited, and that fail to be exhibited.
4. Apply the same behavior-type axis in the human-bot coexistence context as well, diagnosing bots' performance patterns together with them.

## Criteria
If what is measured is actual exhibited behavior (behavior type), it is judged PASS. If the measurement remains an indirect estimate of personality traits (personality type), it is judged FAIL.
