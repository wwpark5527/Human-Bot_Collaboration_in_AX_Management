# Level 1 Tool/Reactive Agent — Method

## Method / Procedure
1. Receive a reaction or API-call request from the higher Level 2 Specialist/Executor.
2. Call the requested API with accurate parameters.
3. Collect the call result immediately, without verification (within the scope of simple reaction).
4. Return the result to the higher level of the hierarchy.

## Criteria
If a response is returned to the request from above by simple reaction or API call alone, it is judged PASS (the Tool/Reactive Agent role is performed); if independent judgment or strategy formulation intervenes, the boundary of the hierarchy has been crossed and it is judged FAIL (the scope of the role is exceeded).
