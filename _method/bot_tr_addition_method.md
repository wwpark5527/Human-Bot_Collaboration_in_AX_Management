# Addition of TR by bots — Method

## Method / Procedure
1. Identify the functions newly required by the organization as a result of the AI bot taking on roles (accountability and alignment management, result verification, interaction design, collaboration flow design, meaning connection, trust management, provenance and traceability management).
2. Confirm that each function does not correspond to any role in the existing human-centered organization.
3. Name and define the confirmed functions as new AX roles (AI Governor, AI Auditor, Prompt Architect, AI Workflow Orchestrator, Human Meaning Integrator, Trust Manager, Provenance Controller).
4. Incorporate the new roles into the organizational structure and the existing TR system.

## Criteria
It is judged PASS (addition mode) if the role in question is a new role that did not exist in a human-centered organization, and FAIL (reclassified into another mode) if it amounts to complementation or augmentation of an existing role.
