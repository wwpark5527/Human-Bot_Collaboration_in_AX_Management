# Augmentation of TR by bots — Method

## Method / Procedure
1. Identify the TRs to be augmented (Monitor-Evaluator ME, Completer-Finisher CF, Resource Investigator RI, Coordinator CO).
2. Confirm the activities each TR has been performing.
3. Map the reinforcement the bot can provide to each TR (ME: data review, risk detection, simulation, search for logical errors / CF: checking documents for errors, confirming schedule omissions, quality inspection, compliance checks / RI: collecting market information, exploring technology trends, competitor analysis, partner search / CO: connecting work flows, role matching, setting collaboration priorities, mediating communication).
4. Measure and confirm the reinforcement effect per TR (ME: reduced intuition bias / CF: reduced fatigue / RI: expanded exploration scope / CO: reduced mediation cost).

## Criteria
It is judged PASS when both the reinforcement the bot provides for a given TR and the resulting effect are confirmed, and FAIL when either the reinforcement or the effect is not confirmed.
