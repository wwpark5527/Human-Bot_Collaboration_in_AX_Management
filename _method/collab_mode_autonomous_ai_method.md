# Autonomous AI — Method

## Method / Procedure
1. Confirm whether the agent performing the work is AI.
2. Check whether a prior human approval procedure exists — if it does, reclassify as Human-in-the-loop.
3. Check whether real-time human assistance exists — if it does, reclassify as AI-in-the-loop.
4. Check whether subsequent and continuous human monitoring (the supervisor position) remains — if it does, reclassify as Human-on-the-loop.
5. When all three forms of human intervention above are absent, determine the type to be Autonomous AI.
6. Record the results of AI autonomous execution and produce them so that subsequent tracing is possible.

## Criteria
When the performing agent is AI and prior human approval, real-time assistance, and subsequent monitoring are all absent (HOOTL), a PASS determination of Autonomous AI is made. If even one of the three exists, reclassify as HITL / AI-in-the-loop / HOTL respectively.
