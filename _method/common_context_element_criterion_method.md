# Criterion — Method

## Method / Procedure
1. Collect the existing ways of judging what counts as a good result in each area of work.
2. Compare the differences among the standards of judgment used by different departments and persons in charge.
3. Consolidate them into one standard of judgment to be unified across the whole organization.
4. Register the unified standard of judgment as a component of the common context.
5. Verify whether the same standard of judgment is applied to the same request.

## Criteria
A PASS judgment is made when the same standard of judgment is applied to the same request rather than answering by a different standard each time; a FAIL judgment is made when the standard varies from request to request.
