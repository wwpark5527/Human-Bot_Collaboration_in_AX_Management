# Feedback — Method

## Method / Procedure
1. Collect cases of errors, failures, and outcomes that occurred in the course of performing work.
2. Analyze which component of the common context — purpose, criterion, role, source, or format — the collected cases relate to.
3. Compile how the standard of the related component should be revised so that the same error is not repeated.
4. Actually reflect the compiled revision proposal in the next version of the common context.
5. Apply the updated common context and verify that the same error does not recur.

## Criteria
A PASS judgment is made when the errors and outcomes that occurred are actually reflected in the next standard (the updated next version of the common context); a FAIL judgment is made when errors are merely recorded and not reflected in the next standard.
