# Format — Method

## Method / Procedure
1. List the types of outputs the organization produces (reports, proposals, training materials, record forms, etc.).
2. Compare, by type, whether the formats currently in use differ by person, by department, and by tool.
3. Define, by type, a standard structure that allows review, comparison, approval, and reuse.
4. Register the standard structure as the format component of the common context.
5. Verify whether outputs are made in the standardized format.

## Criteria
A PASS judgment is made when outputs are not made in a different format by each person, each department, and each tool and allow review, comparison, approval, and reuse; a FAIL judgment is made when the format varies every time.
