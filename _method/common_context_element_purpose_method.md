# Purpose — Method

## Method / Procedure
1. List the areas of work in which the organization uses AI.
2. Collect from stakeholders the reasons AI is used in each area of work.
3. Organize the collected reasons in the organization's own language and document them as a purpose statement.
4. Register the purpose statement together with the other components of the common context (criterion, role, source, format, feedback).
5. Verify whether the purpose is defined in advance in the organization's language.

## Criteria
A PASS judgment is made when, for the work assigned to AI, 'why this work is done' is defined in advance in the organization's language; a FAIL judgment is made when it is not defined and AI has to guess every time.
