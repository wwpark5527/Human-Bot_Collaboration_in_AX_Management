# Source — Method

## Method / Procedure
1. List the kinds of materials (documents, data, regulations, etc.) that AI outputs rely on as grounds.
2. Establish a procedure for confirming whether each material is a verified source.
3. Compose a record system so that the source, standards, revisions, and approval process can be traced after the fact.
4. Inspect cases in which unverified information is presented as if it were fact.
5. Verify whether the source and the original-text confirmation process are built into the system.

## Criteria
A PASS judgment is made when the source, standards, revisions, and approval process can be confirmed after the fact and the accurate source and the original-text confirmation process are built into the system; otherwise, a FAIL judgment is made.
