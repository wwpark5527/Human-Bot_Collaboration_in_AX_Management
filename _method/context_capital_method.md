# Context Capital — Method

## Method / Procedure
1. Define the purpose to be given to AI in the target work domain.
2. Define the (judgment) standards by which AI outputs will be judged.
3. Standardize the language and materials that AI will use.
4. Define the format and verification standards for AI results.
5. Define the approval standards for AI results.
6. Integrate and manage the above elements as the organization's accumulated operating asset (context capital) and, where necessary, structure them as a common context and distribute them to the working unit.

## Criteria
It is judged PASS when purpose, standards, language, materials, format, verification standards, and approval standards are accumulated as a documented operating asset, and FAIL when these elements remain in individuals' tacit knowledge and are not accumulated as an organizational asset.
