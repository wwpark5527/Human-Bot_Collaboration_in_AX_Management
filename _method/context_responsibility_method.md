# Context Responsibility — Method

## Method / Procedure
1. Define the purpose of the work to be entrusted to AI.
2. Stipulate the target users, the organizational standards, and the prohibited conditions.
3. Specify the scope of usable data and the output format.
4. Organize the verification standards and the performance standards and provide them to AI together.

## Criteria
It is judged PASS (context responsibility fulfilled) when the work purpose, target users, organizational standards, prohibited conditions, usable data, output format, verification standards, and performance standards have all been provided to AI. If even one is missing it is judged FAIL (context supplementation needed).
