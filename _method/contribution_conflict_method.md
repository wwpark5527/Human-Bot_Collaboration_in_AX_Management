# Contribution conflict — Method

## Method / Procedure
1. Compare the criteria and interpretation of side A and side B for the same message.
2. Confirm the difference between side A's and side B's judgment of the verification state (verified/unverified).
3. Confirm the difference between side A's and side B's responsibility judgment as to whether it can be shared (shareable/security risk).
4. If a difference is confirmed in one or more items, judge it a contribution conflict and adjust it through one of the three paths: human-centered, AI-centered, or via governance.

## Criteria
It is judged PASS (a contribution conflict exists) when one or more of the criteria, interpretation, verification state, and responsibility judgment for the same message diverge between side A and side B, and FAIL (no contribution conflict) when they all agree.
