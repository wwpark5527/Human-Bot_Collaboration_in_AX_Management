# AH + B (intelligent division of labor) — Method

## Method / Procedure
1. Confirm whether the member composition consists of one augmented human (AH) and multiple bots (B).
2. Check respectively whether the human is in an augmented state (AH) and whether the bots are in a non-augmented state (B).
3. Confirm whether the division-of-labor configuration in which the human formulates strategy and the bots execute it actually holds.
4. If all the above conditions are satisfied, judge it as the AH + B type, and check whether a multi-agent environment, human-in-the-loop, and role-based agent design are applied.
5. Carry out building a multi-agent environment, human-in-the-loop design, and role-based agent design.

## Criteria
When, in a state where the human is augmented but the bots are not, one AH orchestrates many Bs, a PASS judgment is made as the AH + B type. If the bots are also augmented it is reclassified as AH + AB, and if the human is not augmented it is reclassified as H+B or H+AH.
