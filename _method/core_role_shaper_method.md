# Shaper/Designer — Method

## Method / Procedure
1. Define the problem to be solved.
2. Organize the requirements.
3. Decide what to build.
4. Make clear the grounds for why it should be built.
5. Design what structure is appropriate.

## Criteria
If all three of what to build, why it should be built, and what structure is appropriate are defined it is judged PASS (clarity secured — the ambiguous problem has been converted into a clear one), and if even one of them is not defined it is judged FAIL (insufficient problem definition).
