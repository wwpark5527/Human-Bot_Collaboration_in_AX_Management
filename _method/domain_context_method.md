# Domain Context — Method

## Method / Procedure
1. Confirm the organization's common context (the standard of work criteria).
2. Specify the work area (domain) to which it is to be applied.
3. Make common context concrete to fit the actual units of work of that domain and reconstitute it into an executable structure.
4. Derive skills from the concretized domain context and pass them on to the on-site execution stage.

## Criteria
It is determined by whether the general criteria of common context have been made concrete into an executable structure fitting a particular work area. Remaining at the level of an abstract standard is regarded as unmet, and being reconstituted into a form actually applicable is regarded as met.
