# Authority — Method

## Method / Procedure
1. Survey, for each local context in the organization, the current state of the materials and tools AI actually uses.
2. Define, per context, the scope of materials and tools to which access should be permitted.
3. Confirm by mapping whether the defined scope satisfies the requirements of ISO/IEC 42001 role/access control, NIST AI RMF Govern, and EU AI Act human oversight (Article 14).
4. Register the access scope as the authority component of the governance context and apply it in execution.
5. Check that no access occurs outside the authority scope.

## Criteria
PASS is determined when which context can access which materials and tools is clearly defined and actual access does not go outside that scope; FAIL is determined when authority confusion (it being unclear which AI can access which materials and tools) occurs.
