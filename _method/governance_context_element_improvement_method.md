# Improvement — Method

## Method / Procedure
1. Collect cases of errors, failures, and feedback that have arisen in the course of AI operation.
2. Identify the criteria (policies, prompts, verification checklists, authority scopes, and so on) into which the collected errors and feedback should be reflected.
3. Define the reflection procedure (who updates the criteria, when, and in what way).
4. Confirm whether the defined improvement system satisfies the requirements of ISO/IEC 42001 continual improvement, NIST Manage, and EU AI Act post-market monitoring.
5. Register the improvement system as the improvement component of the governance context and reflect it in the actual operating cycle.

## Criteria
PASS is determined when where errors and feedback are reflected is clearly defined and organizational learning and improvement of criteria take place; FAIL is determined when errors and feedback are not reflected into the next set of criteria.
