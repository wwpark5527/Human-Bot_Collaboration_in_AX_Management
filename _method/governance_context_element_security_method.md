# Security — Method

## Method / Procedure
1. Survey, per context, the current state of information that is entered into AI or that AI can generate or share.
2. Identify the items that fall under sensitive information and confidentiality.
3. Define, per context, the handling criteria for information whose entry, sharing, or generation must be prohibited.
4. Confirm whether the defined criteria satisfy the requirements of ISO/IEC 42001 data/asset management, NIST Map/Manage, and EU AI Act data governance (Article 10).
5. Register the security criteria as the security component of the governance context and check that no boundary violation occurs.

## Criteria
PASS is determined when which information must not be entered, shared, or generated is clearly defined and actual operation observes those criteria; FAIL is determined when the boundary between sensitive information and externally disclosable information collapses.
