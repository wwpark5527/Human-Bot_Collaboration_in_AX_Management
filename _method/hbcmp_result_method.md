# Result — Method

## Method / Procedure
1. Confirm whether the agent whose stress is being neglected is a human or a bot.
2. If human, check whether signs of Burnout or dissatisfaction are observed.
3. If a bot, check whether signs of performance degradation or errors are observed.
4. Record the observed consequence as the value of the result axis, and pass it on to the follow-up response procedure of that family.

## Criteria
If Burnout or dissatisfaction is observed, it is judged PASS as a human stress result, and if performance degradation or errors are observed, it is judged PASS as a bot stress result. If signs of neither family are observed, it is judged FAIL (consequence unconfirmed, re-observation required).
