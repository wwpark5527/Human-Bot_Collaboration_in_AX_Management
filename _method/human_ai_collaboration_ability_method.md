# Human-AI Collaboration Ability — Method

## Method / Procedure
1. Confirm whether the target work can be decomposed so as to distinguish the parts to entrust to AI from the parts humans will handle.
2. Confirm whether one can judge how to connect the work of AI and humans.
3. Check whether work is actually being performed by dividing roles with or collaborating with bots.
4. If one is still handling all work alone, rewrite and apply the role-division design.

## Criteria
If one judges what to entrust to AI, what humans should do, and how to connect them, and is actually dividing roles and collaborating with bots, it is judged PASS (a collaborative human). If one is still performing all work alone, it is judged FAIL (redesign of role division is needed).
