# AI Accessibility — Method

## Method / Procedure
1. Fix the scope of the AI tools to be measured — enumerate the tools and infrastructure required for carrying out work, and state explicitly the conditions to be judged as "accessible" (holding an account, actual usage authority, completion of usage training, and so on).
2. Calculate the employee AI-tool access rate — compute the proportion of people with access relative to all employees according to the standard in 1.
3. Calculate the per-department access rate — apply the same standard at the department level to produce a value for each department.
4. Calculate the inter-departmental access gap — present the difference between the highest and lowest departments together with the per-department distribution.
5. Present the access rate and the gap bound together as one reporting unit. A form that reports only the average is not regarded as fulfilment of this indicator.
6. Fix a measurement cycle and accumulate a time series on the same standard, to confirm the trend of whether the gap is narrowing or widening.

## Criteria
With the access judgment standard stated explicitly, it is PASS when **both the employee AI-tool access rate and the inter-departmental access gap** are calculated, the two values are reported together, and a time series on the same standard is accumulated. It is judged FAIL if the access judgment standard is unclear so that the figures are not reproducible, or if only the company-wide average access rate is calculated and the per-department gap is not produced. The latter ends up hiding the exclusion of a particular department behind the average value and therefore runs counter to the purpose of this indicator.
