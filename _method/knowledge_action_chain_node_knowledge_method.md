# knowledge — Method

## Method / Procedure
1. Collect the data scattered within the organization.
2. Organize the data into information.
3. Systematize the information into knowledge.
4. Connect the knowledge to other knowledge and build a structure that serves as the basis for judgment.
5. Confirm whether "what do we know" can be answered, while recognizing that this is a static structure with no execution or results yet.

## Criteria
If data, information, and knowledge are connected so that "what do we know" can be answered, it is judged PASS; if the connections are broken or it cannot be answered, FAIL. However, this PASS means only that a structure of knowing has been secured, and it is separate from the execution and result stages (from skill onward).
