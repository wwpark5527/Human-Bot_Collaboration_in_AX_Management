# runtime (SkillRuntime) — Method

## Method / Procedure
1. Confirm the skill converted at the 'skill' node.
2. Define what the input is.
3. Define the materials to be used.
4. Define the tools to be used.
5. Define the prohibitions (what must not be done).
6. Define the result format.
7. Define the reviewer and approver.
8. Define the record location and thereby complete an executable skill-execution structure.

## Criteria
If all seven items — input, materials, tools, prohibitions, result format, review approver, record location — are defined, it is judged PASS; if even one is undefined, FAIL.
