# skill — Method

## Method / Procedure
1. From the deliverable of the 'knowledge' node (the basis-for-judgment structure), identify the work that must be executed repeatedly.
2. Review the related documents (policies, legal standards, how to write minutes, and the like).
3. Convert the documents into executable skills (policy-based answer verification, contract risk analysis, meeting summary and action derivation, and the like).
4. Confirm whether the converted result is a "skill meant to be executed" rather than a "document meant to be read."

## Criteria
If that knowledge has been converted into an executable skill it is judged PASS; if it still remains in the state of a document meant to be read, FAIL.
