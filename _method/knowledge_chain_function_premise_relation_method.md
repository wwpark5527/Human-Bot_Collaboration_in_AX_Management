# Premise-Relation Measurement — Method

## Method / Procedure
1. Identify the advanced concept (expression) to be checked and the lower concept that underlies it.
2. Check the connection state between the higher concept and the lower concept.
3. Detect whether there are cases of speaking about the advanced concept without having understood the foundational concept.
4. If a foundational-concept deficiency is found, judge it as "a state where the words are advanced but the foundational concept is weak."

## Criteria
If whether the foundational concept that is the premise of the advanced expression is understood (whether there is a deficiency) is actually judged, it is PASS; if the higher-lower connection state cannot be confirmed, FAIL.
