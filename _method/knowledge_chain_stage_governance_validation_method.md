# Governance Validation — Method

## Method / Procedure
1. Confirm the interpretation context produced in the organizational context reference stage and the response candidate scheduled to be generated.
2. Check that context and response candidate against each of the organization's standards of authority (scope of access), security (handling of sensitive information), verification (quality standards), and approval (necessary conditions for human intervention).
3. Confirm whether there is any item that does not pass the standards, and if there is, block the response candidate.
4. Record the validation result and its grounds so that accountability tracing is possible.
5. Pass the response candidate that has passed validation on to the next stage (response generation).

## Criteria
It is judged PASS when verification and accountability tracing are possible and the existing LLM's defect that "verification/accountability tracing is difficult" is resolved, and FAIL when the grounds of verification or the locus of accountability cannot be traced.
