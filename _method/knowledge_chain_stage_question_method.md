# Question — Method

## Method / Procedure
1. Collect the requests that humans or AIs pose to the organization.
2. Check whether that request is at risk of being consumed one-off as "question → answer → end," in the manner of existing LLMs.
3. Structure the request into a request unit that is passed on to the subsequent stage (organizational context reference).
4. Confirm whether the structured question has been incorporated as the first node of the circulation/accumulation structure of the knowledge chain.

## Criteria
It is judged PASS when that question is connected onward to context reference, validation, and recording, and FAIL when it is consumed one-off and ends.
