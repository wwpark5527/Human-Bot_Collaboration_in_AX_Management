# Execution model — Method

## Method / Procedure
1. Take as input the concepts theorized at the proposed-concept layer.
2. Design the impact assessment procedure for executing those concepts.
3. Build the authority design, verification, and approval procedures.
4. Prepare a recording system so that the execution history is traceable.
5. Design a performance-sharing system.
6. Build an improvement loop so that the operating model is continuously updated.

## Criteria
It is judged PASS when impact assessment, authority design, verification, approval, recording, performance sharing, and improvement loops are all concretized into procedures executable in organizational operations, and FAIL when one or more of them remain at the theoretical stage.
