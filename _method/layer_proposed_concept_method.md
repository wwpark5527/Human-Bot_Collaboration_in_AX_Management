# Proposed concept — Method

## Method / Procedure
1. Take as input the problem diagnosed at the reasonable interpretation layer (the possibility that a gap arises).
2. Design a new concept that responds to that problem (for example, inclusive AI-transition ESG, context access rights, a responsible operating system).
3. Determine that the designed concept is the author's new proposal — confirm that it is newly theorized rather than a fact verified in the existing literature.
4. Organize the theorized concept into the "proposed concept" layer.

## Criteria
It is judged PASS if a new concept is explicitly proposed and theorized from the problem diagnosis, and FAIL if it merely restates existing verified facts without any new concept.
