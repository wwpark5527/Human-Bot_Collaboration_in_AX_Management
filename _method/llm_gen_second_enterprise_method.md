# The Second LLM — Method

## Method / Procedure
1. Confirm whether the target model is an upper architecture built on top of the existing LLM (the first LLM).
2. Check whether the paradigm change (the shift from text generation to knowledge control) has occurred.
3. Check whether the change in operating entity (big tech → the individual enterprise internalizing its own rule set) has occurred.
4. When both changes are confirmed, determine it to be the 'second LLM'.

## Criteria
It is determined by two changes. (1) The change in paradigm = the shift from text generation to knowledge control, (2) the change in operating entity = the shift from big tech to the individual enterprise. The criterion is whether the enterprise has laid its own rule set on top and internalized it.
