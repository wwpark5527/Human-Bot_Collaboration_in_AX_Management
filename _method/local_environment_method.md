# Local environment — Method

## Method / Procedure
1. List the individual tasks that AI actually performs.
2. Inspect whether the purpose, standards, role, source, format, and feedback of each task are defined.
3. Mark undefined items as common-context blanks.
4. Compose a local work context so that humans and AI work according to the same purpose, standards, role, source, and format.
5. Verify whether the composed local work context can answer "By what standards is this task performed?"

## Criteria
It is judged PASS if purpose, standards, role, source, format, and feedback are all managed within that task, and FAIL if even one of them is undefined.
