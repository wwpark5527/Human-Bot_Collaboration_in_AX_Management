# Meaning design capability — Method

## Method / Procedure
1. List the meaning elements (vision, identity, community meaning, and so on) related to the target organization and its work.
2. Grasp the relations among the meaning elements, large and small, and among meanings of various types.
3. On the basis of the grasped relations, structure them into a single meaning system.
4. Confirm whether the structured meaning system supports problem framing.

## Criteria
It is judged PASS (meaning design capability secured) if one has grasped meaning and formed relations among meanings of various types so as to create a meaning system that supports problem framing. It is judged FAIL (the meaning system needs to be redesigned) if grasping meaning or forming relations has failed.
