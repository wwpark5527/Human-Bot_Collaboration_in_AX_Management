# Network environment — Method

## Method / Procedure
1. List the multiple local environments (individual work contexts) within the organization.
2. Identify the points at which local work contexts are connected.
3. At each connection point, inspect whether authority, security, verification, approval, recording, responsibility, and improvement are managed.
4. Mark undefined items as governance-context blanks.
5. Compose a network operating context so that local work contexts are connected, verified, approved, recorded, and improved across the whole organization.
6. Verify whether the composed network operating context can answer "By what standards are multiple work environments connected and managed?"

## Criteria
It is judged PASS if authority, security, verification, approval, recording, responsibility, and improvement are all managed at the organizational level, and FAIL if even one of them is undefined.
