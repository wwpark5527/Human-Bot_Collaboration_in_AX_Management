# World model — Method

## Method / Procedure
1. Represent the current state of the environment as data.
2. Train a model that predicts state changes.
3. Simulate the results of each candidate action.
4. Compare several paths and select the path closest to the goal.
5. Simulate and review the risks before actual execution.

## Criteria
PASS (the world model level) is judged when the core question "what will happen" can be answered, and FAIL (the general generative AI level) when it stops at generating responses to the current input.
