# Problem Framing Capability — Method

## Method / Procedure
1. Review the situation and list the candidate problems that could be addressed.
2. Discriminate whether each candidate problem is essential or merely a surface symptom.
3. Decide which direction matters on the basis of the essential problem, and define the problem.
4. Before passing the defined problem to AI, check whether the human has performed the role of problem framer on their own.

## Criteria
If one can settle on one's own which problem is to be solved, what is essential, and which direction matters, it is judged PASS (problem framer). If one depends on the answers presented by AI and cannot even define the problem on one's own, it is judged FAIL (remaining an answer generator, redefinition needed).
