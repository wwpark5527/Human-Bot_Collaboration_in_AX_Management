# Problem Definer — Method

## Method / Procedure
1. Clarify the problem by describing concretely what the object to be solved is.
2. Describe why this problem is importantly connected to work and performance.
3. Establish the standards for what result (deliverable) is needed.
4. Check constraints such as security, cost, time, and legal conditions.
5. Set the performance indicators by which success will be judged.

## Criteria
When all five items — what is the problem, why does it matter, what result is needed, what constraints exist, and what are the success criteria — are clearly defined, it is judged PASS (problem definition complete). If even one is unclear, it is judged FAIL (problem definition needs supplementation).
