# Result Interpreter — Method

## Method / Procedure
1. Review whether the AI result fits our organization's situation.
2. Judge the validity of the core logic.
3. Check the executability of the result.
4. Inspect whether anything is missing.
5. Check whether there is any dangerous interpretation and organize it in a form usable in decision-making.

## Criteria
When all six items — does it fit our organization's situation, is the core logic valid, is it executable, is anything missing, is there any dangerous interpretation, and can it be used in decision-making — are satisfied, it is judged PASS (convertible into organizational judgment). If even one is unsatisfied, it is judged FAIL (reinterpretation needed).
