# Input — Method

## Method / Procedure
1. Identify what input is needed when the target skill is executed.
2. Specify the format and scope of the input.
3. Document and finalize the input specification.
4. Pass the finalized input specification on to the definition of the next slot of SkillRuntime (material).

## Criteria
It is judged PASS when what the input is has been specified in advance, and FAIL when it has not been specified.
