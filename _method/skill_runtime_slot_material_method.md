# Material — Method

## Method / Procedure
1. Identify which materials are needed when the target skill is executed.
2. Specify the reference scope of the usable materials.
3. Document and finalize the list of materials.
4. Pass the finalized list of materials on to the definition of the next slot of SkillRuntime (tool).

## Criteria
It is judged PASS when which materials will be used has been specified, and FAIL when it has not been specified.
