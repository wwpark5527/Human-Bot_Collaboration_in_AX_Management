# Record Location — Method

## Method / Procedure
1. Identify where the execution process and results of the target skill are to be recorded.
2. State a traceable record location.
3. Document and finalize the record location.
4. With the finalized record location, complete the definition of the seven SkillRuntime slots (input · material · tool · prohibition · result format · review and approver · record location).

## Criteria
It is judged PASS when where it is recorded has been specified, and FAIL when it has not been specified.
