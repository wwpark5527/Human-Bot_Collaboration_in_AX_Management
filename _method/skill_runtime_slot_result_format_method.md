# Result Format — Method

## Method / Procedure
1. Identify what format the output of the target skill's execution must take.
2. State the standardized output format explicitly.
3. Document and settle the result format.
4. Hand the settled result format over to the definition of the next slot of SkillRuntime (reviewer/approver).

## Criteria
It is judged PASS if what the result format is has been specified, and FAIL if it has not been specified.
