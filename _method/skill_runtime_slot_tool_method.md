# Tool — Method

## Method / Procedure
1. Identify which tools are needed when the target skill executes.
2. State the scope of execution means of the allowed tools explicitly.
3. Document and settle the list of tools.
4. Hand the settled list of tools over to the definition of the next slot of SkillRuntime (prohibition).

## Criteria
It is judged PASS if which tools will be used has been specified, and FAIL if it has not been specified.
