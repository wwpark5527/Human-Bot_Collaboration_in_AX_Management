# 2. Build AI Context Capital — Method

## Method / Procedure
1. Take the results of step 1, AI impact assessment, as input, define the task units for which context capital will be built, and set their priorities.
2. Organize the six items in order for each task — purpose (what the task is for), criteria (by what yardstick judgment is made), sources (on what materials it is grounded), roles (who performs it and is accountable), formats (what form the output takes), verification standards (how it is checked that the result is correct).
3. Accumulate the six organized items in a form AI can reference and provide access paths to them.
4. Calculate the per-task context-capital build rate to identify and supplement the tasks not yet built.
5. Set a refresh cycle and update regularly, and mark context capital that has passed the cycle as an obsolete item and reorganize it.

## Criteria
PASS if all six items — purpose, criteria, sources, roles, formats, and verification standards — are organized for each task and accumulated in a form AI can reference, and the build rate and the refresh cycle are measured and managed. It is judged FAIL if only some of the six items are organized, or if, even when organized, the refresh cycle is not managed and it is left in an obsolete state. (ESG linkage: S / G)
