# Cognitive Augmentation (Cognitive A.) — Skill

## Purpose
Measure whether the use of AI actually expands a member's range of thinking (cognition), and thereby confirm the first indicator of whether the augmented human (AH) has been realized.

## Input
- Records of problem solving without the use of AI (the baseline)
- Records of problem solving with the use of AI

## Procedure (Steps)
1. Record the number of alternatives generated and the number of variables considered in the state without AI use.
2. Record the number of alternatives generated and the number of variables considered in the state with AI use.
3. Compare thinking depth and cognitive speed in the two states.
4. Combine the three measures and judge whether cognitive augmentation has occurred.

## Output
A comparison table of the number of alternatives generated, a comparison table of the number of variables considered, and measurement results for thinking depth / cognitive speed.

## Criteria
If the number of alternatives generated, the number of variables considered, and thinking depth / cognitive speed have improved after the use of AI, it is judged PASS (cognitive augmentation confirmed); if they have not improved, it is judged FAIL (cognitive augmentation not confirmed).
