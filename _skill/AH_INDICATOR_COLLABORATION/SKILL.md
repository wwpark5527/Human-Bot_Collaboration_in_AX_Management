# Collaboration Augmentation (Collaboration A.) — Skill

## Purpose
Measure whether AI is used naturally as a collaboration partner that shares the work, and thereby confirm the fourth indicator of whether the augmented human (AH) has been realized.

## Input
- The member's work list
- Records of the member's agent usage

## Procedure (Steps)
1. Calculate the proportion of work in the work list that can be delegated to AI (an agent).
2. Measure the member's level of agent usage (role-dividing use as against simple invocation).
3. Comprehensively review the proportion of delegable work and the level of agent usage.
4. Judge whether collaboration augmentation has occurred on the basis of the combined result.

## Output
A table of the proportion of delegable work, a measurement table of the level of agent usage, and the collaboration augmentation judgment result.

## Criteria
If the proportion of delegable work and the level of agent usage appear at a meaningful level, it is judged PASS (collaboration augmentation confirmed); otherwise it is judged FAIL (collaboration augmentation not confirmed).
