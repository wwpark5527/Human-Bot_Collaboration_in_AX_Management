# Physical Augmentation — Skill

## Purpose
Complement and extend a human's physical limits or physical performance capability with technology, thereby satisfying the physical axis among the three augmentation dimensions an augmented human (AH) must possess.

## Input
- The current state of the human member's physical limits and physical performance capability
- Candidate complementing and extending technologies (tools, equipment, systems) that can be applied

## Procedure (Steps)
1. Grasp the current level of the human member's physical limits and physical performance capability.
2. Investigate technical means that can complement and extend those limits.
3. Apply the investigated technical means to actual work.
4. Confirm whether physical performance capability has actually been complemented and extended after application.

## Output
Physical performance capability that has been complemented and extended by technology.

## Criteria
If it is confirmed that physical limits and physical performance capability have been complemented and extended by technology, it is judged PASS (physical augmentation confirmed); otherwise it is judged FAIL (physical augmentation not confirmed).
