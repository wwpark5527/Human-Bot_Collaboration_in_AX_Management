# Augmentation User — Skill

## Purpose
Judge whether a member has reached the Augmentation User stage, the final stage of the AI-utilization ladder, at which AI operates as if it were part of oneself and augments memory, analysis, and creativity, thereby completing the AI-utilization measurement and securing the input for calculating the Augmentation Quotient (AQ).

## Input
- Records of decision quality, learning speed, and productivity before using AI (the baseline)
- Records of the same indicators after using AI

## Procedure (Steps)
1. Record decision quality, learning speed, and productivity before using AI.
2. Record the same indicators after using AI.
3. Compare the changes against the baseline.
4. From the amount of change, judge "After using AI, have I become a different person from my earlier self?"

## Output
A measurement table of improved decision quality, a measurement table of increased learning speed and productivity, and the Augmentation User stage judgment result.

## Criteria
If decision quality, learning speed, and productivity have improved together, it is judged PASS (falls into the Augmentation User stage); otherwise it is judged FAIL (does not fall into the Augmentation User stage).
