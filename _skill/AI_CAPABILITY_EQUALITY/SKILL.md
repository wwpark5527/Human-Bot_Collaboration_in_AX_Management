# AI Capability Equality Theory — Skill

## Purpose
Diagnose the cause of AI-era inequality accurately as a capability gap rather than access to AI tools, and secure equality of AI-utilization capability by converting context capital, the authority system, verification standards, and the approval structure into a common production base for the whole organization.

## Input
- AI-utilization performance/gap data within the organization, the current state of the capability to convey purpose, standards, and context and the capability to verify, approve, and improve by individual and department, existing context capital and authority system documents (where they exist)

## Procedure (Steps)
1. Observe the gaps in AI-utilization performance and diagnose the cause by distinguishing tool access gap vs. capability gap.
2. Evaluate, by individual and by department, the capability to convey purpose, standards, and context and the capability to verify, approve, and improve results.
3. Identify structures in which AI-utilization capability depends on individual intuition or a particular department's authority.
4. Convert context capital, the authority system, verification standards, and the approval structure into a common production base for the whole organization.
5. Re-measure after the conversion whether the capability gap has narrowed.

## Output
Diagnostic report on the cause of the capability gap, capability evaluation results by individual/department, the converted context capital/authority system/verification standards/approval structure, gap re-measurement report.

## Criteria
If the cause of inequality is accurately diagnosed as a capability gap and context capital, the authority system, verification standards, and the approval structure have been converted into a common organizational production base, it is determined PASS; if they are left to an individual's intuition or a particular department's authority, it is determined FAIL.
