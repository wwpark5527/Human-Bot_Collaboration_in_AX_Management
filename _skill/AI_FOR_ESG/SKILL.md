# AI for ESG — Skill

## Purpose
Use AI as a powerful implementation tool for ESG to accelerate ESG data collection, analysis, monitoring, and reporting, and spread its positive effects across the organization.

## Input
- The organization's ESG implementation process documents, available AI tools/models, existing ESG performance data

## Procedure (Steps)
1. Organize the ESG implementation process (data collection, measurement, monitoring, reporting) stage by stage.
2. Identify the points where AI can be applied at each stage.
3. Automate ESG data collection, analysis, and monitoring with AI-based tools.
4. Comparatively measure performance before and after applying AI.
5. Document and spread the cases in which positive effects were confirmed.

## Output
List of ESG implementation points where AI is applied, AI-based ESG monitoring and reporting system, casebook of performance improvements.

## Criteria
If measurement confirms improvement in the speed, accuracy, and scope of the ESG implementation process through the application of AI, it is determined PASS; if not confirmed, it is determined FAIL.
