# Augmented Human Index (AHI) — Skill

## Purpose
As the stage following the Augmentation Quotient (AQ, potential), it produces the Augmented Human Index (AHI, realization) to complete the AIU → AQ → AHI measurement system and makes the final judgment on "whether that person is actually an AH."

## Input
- Measurement data on Performance
- Measurement data on Learning (learning speed)
- Measurement data on Influence, Innovation, and Adaptability
- The AQ value produced at the preceding stage

## Procedure (Steps)
1. Measure the change in Performance.
2. Measure the change in Learning.
3. Measure the changes in Influence, Innovation, and Adaptability.
4. Synthesize the five elements as a function to compute AHI.
5. Make the final judgment on "whether the person is actually an AH" from the AHI result.

## Output
The produced AHI value and the final judgment result on whether the person is an AH.

## Criteria
If problem-solving ability, learning speed, decision-making, and collaboration ability have improved together, it is judged PASS (judged to be an AH); if, with declining judgment and reduced creativity, the person depends solely on AI, it is judged FAIL (not an AH).
