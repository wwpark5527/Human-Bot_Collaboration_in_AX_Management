# AI-Centered Path — Skill

## Purpose
It constructs the AI-centered path in AH-AH communication situations where speed matters and determines whether the human's intent is preserved.

## Input
- The communication situation in question (message exchange between augmented humans A and B)
- Whether processing efficiency is the priority

## Procedure (Steps)
1. Confirm whether processing efficiency is the priority.
2. Set the structure in which the human provides only the purpose and the approval criteria while the AI relays and structures (Human A ↔ AI A ↔ AI B ↔ Human B).
3. Compare the result of the AI's processing against the human's original intent.
4. Determine whether there is distortion and, if necessary, have the human intervene.

## Output
The construction of a processing-efficiency-type AH-AH communication path (the AI-centered path).

## Criteria
If the processing speed is fast and the human's intent is preserved, it is judged PASS; if the intent is distorted, it is judged FAIL.
