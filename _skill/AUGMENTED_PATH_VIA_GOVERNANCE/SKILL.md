# Via-Governance Path — Skill

## Purpose
It constructs the via-governance path in AH-AH communication situations where accountability matters and determines whether the criteria are passed.

## Input
- The communication situation in question (message exchange between augmented humans A and B)
- Whether it falls within an accountability domain (organizations/contracts/legal/finance/public sector/healthcare/education and so on)

## Procedure (Steps)
1. Confirm whether it is a domain where accountability matters.
2. Set the message into the structure of passing through the governance context (Human A ↔ AI A ↔ governance context ↔ AI B ↔ Human B).
3. Check in order the criteria of authority, security, verification, approval, recording, and accountability.
4. Deliver the message only when all criteria are passed.

## Output
The construction of an accountability-establishing AH-AH communication path (the via-governance path).

## Criteria
If all six criteria (authority, security, verification, approval, recording, accountability) are passed, it is judged PASS; if even one is not passed, it is judged FAIL.
