# Behavior Type vs Personality Type — Skill

## Purpose
By carrying out team role diagnosis on the basis of the direct measurement of behavior type rather than the indirect estimation of personality type, provide the foundation of an accurate and direct methodology for increasing team performance and secure a consistent diagnostic axis in human-bot coexistence organizations as well.

## Input
- Observation and self-diagnosis data for each individual member (human/bot)
- Existing personality-type test results (for comparison in making the distinction, where available)

## Procedure (Steps)
1. Collect self-diagnosis and observer-diagnosis data on each individual's actual exhibited behavior.
2. Diagnose with behavior-type measurement instruments, distinguished from personality-type tests.
3. Organize the results by distinguishing the behavior types that are exhibited, that might be exhibited, and that fail to be exhibited.
4. Apply the same axis in the human-bot coexistence context as well, diagnosing bots' behavior types (performance patterns) together with them.

## Output
Behavior-type diagnosis results for each individual (human/bot), and a document of the grounds for distinguishing it from the estimation of personality type.

## Criteria
If what is measured is actual exhibited behavior (behavior type), it is judged PASS; if it remains an indirect estimate of personality traits (personality type), it is judged FAIL.
