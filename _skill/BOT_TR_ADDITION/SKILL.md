# Addition of TR by bots — Skill

## Purpose
Name and define, as new AX roles, the functions newly required by the AI bot taking on roles that did not exist in a human-centered organization, and incorporate them into the organizational structure.

## Input
- The current state of AI bot use within the organization and the list of management, verification, and design needs newly arising from it
- The role/functional role system of the existing human-centered organization

## Procedure (Steps)
1. Identify the functions newly required by the organization as a result of the AI bot taking on roles.
2. Confirm that each function does not correspond to the existing human role system.
3. Name and define the confirmed functions as new AX roles.
4. Incorporate the new roles into the organizational structure.

## Output
A definition table of the 7 new AX roles (AI Governor, AI Auditor, Prompt Architect, AI Workflow Orchestrator, Human Meaning Integrator, Trust Manager, Provenance Controller) and documentation of their responsibilities.

## Criteria
It is judged PASS if the role in question is a new role that did not exist in a human-centered organization, and FAIL if it amounts to complementation or augmentation of an existing role.
