# Augmentation of TR by bots — Skill

## Purpose
Use the bot's strengths (computation, memory, exploration, repetition, pattern recognition, real-time optimization) to augment (reinforce) human performance across the four TRs of ME/CF/RI/CO, and confirm the reinforcement effect per TR.

## Input
- TR diagnostic results for the target team members (whether Monitor-Evaluator ME, Completer-Finisher CF, Resource Investigator RI, or Coordinator CO)
- The current state of tools within the organization by which bots/AI can support data review, exploration, quality inspection, and work flow connection

## Procedure (Steps)
1. Identify the TRs to be augmented (ME/CF/RI/CO).
2. Confirm the existing activities performed by each TR.
3. Map the reinforcement the bot will provide to each TR.
4. Measure and confirm the reinforcement effect per TR.

## Output
A mapping table of the bot's reinforcement content for each of the 4 TRs (ME/CF/RI/CO), and records confirming the reinforcement effect per TR (reduced intuition bias / reduced fatigue / expanded exploration scope / reduced mediation cost).

## Criteria
It is judged PASS when both the reinforcement the bot provides for a given TR and the resulting effect are confirmed, and FAIL otherwise.
