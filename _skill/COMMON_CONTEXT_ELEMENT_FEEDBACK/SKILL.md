# Feedback — Skill

## Purpose
Judge whether the experience of errors and failures is fed back into the next common context so that the common context becomes an updated standard rather than a fixed document.

## Input
- Records of errors, failures, and outcomes that occurred in the course of performing work
- The current version of the common context (purpose, criterion, role, source, format)

## Procedure (Steps)
1. Collect cases of errors, failures, and outcomes.
2. Classify which component of the common context each case relates to.
3. Derive a revision proposal to be reflected in the next version of the common context.
4. Judge whether the revision proposal was actually reflected in the next version and whether the same error does not recur.

## Output
The formation of organizational learning. The updated next version of the common context.

## Criteria
A PASS judgment is made when the errors and outcomes that occurred are actually reflected in the next standard; a FAIL judgment is made when they are not reflected and are repeated.
