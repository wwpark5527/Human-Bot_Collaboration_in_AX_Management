# Format — Skill

## Purpose
Inspect the standard structure of each output type and judge whether it is standardized into a format that allows review, comparison, approval, and reuse.

## Input
- A list of output types (reports, proposals, training materials, record forms, etc.)
- Materials on the formats currently in use by type

## Procedure (Steps)
1. Identify the types of outputs the organization produces.
2. Compare, by type, whether the current format differs by person, department, and tool.
3. Define a standard structure that allows review, comparison, approval, and reuse.
4. Judge whether outputs are made in the standardized format.

## Output
The judgment result on standardized outputs (results made into a structure that can be repeated, compared, reviewed, and reused).

## Criteria
A PASS judgment is made when outputs are not made in a different format by each person, each department, and each tool and allow review, comparison, approval, and reuse; otherwise, a FAIL judgment is made.
