# Context Capital — Skill

## Purpose
Build the purpose, standards, language, materials, format, verification standards, and approval standards needed to direct AI into the organization's accumulated operating asset (context capital).

## Input
- The target work domain, existing practices of AI use, and materials related to the organization's judgment standards and approval system (where they exist)

## Procedure (Steps)
1. Define the work purpose to be given to AI.
2. Define the (judgment) standards by which AI outputs will be judged.
3. Standardize the language and materials that AI will use.
4. Define the format and verification standards for AI results.
5. Define the approval standards for AI results.
6. Integrate the above elements, accumulate them as the organization's context capital and, where necessary, structure them as a common context.

## Output
A definition document for purpose and judgment standards, language and material standards, a verification standards document, an approval standards document, and an integrated context capital repository.

## Criteria
It is judged PASS when purpose, standards, language, materials, format, verification standards, and approval standards are accumulated as a documented operating asset, and FAIL when they remain in individuals' tacit knowledge and are not turned into an organizational asset.
