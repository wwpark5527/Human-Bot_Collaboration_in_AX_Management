# Context Responsibility — Skill

## Purpose
So that AI does not produce generic answers without context, support the fulfilment of the responsibility to provide a work context aligned with the organization's purpose and standards.

## Input
- An overview of the work to be delegated to AI
- The organization's purpose, standards, prohibited conditions, and the current state of usable data

## Procedure (Steps)
1. Clearly define the work purpose.
2. Stipulate the target users, the organizational standards, and the prohibited conditions.
3. Specify the usable data and the required output format.
4. Organize the verification standards and the performance standards and convey them to AI.

## Output
A work context aligned with the organization's purpose and standards (the set of input conditions for AI work).

## Criteria
It is judged PASS (context responsibility fulfilled) when the work purpose, target users, organizational standards, prohibited conditions, usable data, output format, verification standards, and performance standards have all been provided to AI, and FAIL (context supplementation needed) if even one is missing.
