# DX (Digital Transformation) — Skill

## Purpose
Diagnose the organization's level of digital transformation (DX) and design a plan for digitization, datafication, cloud migration, and process efficiency.

## Input
- The organization's current state of work, systems, and data
- DX-era question checklist (digitization, data storage, automation, system adoption, efficiency)

## Procedure (Steps)
1. Check whether work and systems have been digitized.
2. Evaluate and design the method of data storage and cloud migration.
3. Identify the targets for process automation and establish an automation plan.
4. Establish goals for the adoption of new systems and for efficiency improvement.

## Output
Digitization diagnosis document, data and cloud design document, process automation plan, system and efficiency roadmap.

## Criteria
It is determined PASS when the answers to the questions of all five axes (digitization, data storage, automation, system adoption, efficiency) are reflected in the deliverables.
