# Domain Context — Skill

## Purpose
Discriminate whether common context has been made concrete into a domain context (an executable structure) fitting a particular work area.

## Input
- The definition of the organization's common context
- Information on the target work area (domain)
- The current status of the linkage to skill derivation and on-site execution

## Procedure (Steps)
1. Confirm the common context (the standard of work criteria).
2. Identify the target domain.
3. Reconstitute common context into an executable structure actually applicable to fit the domain.
4. Confirm whether skill derivation and the linkage to on-site execution follow from the domain context.

## Output
A domain context definition document, and the results of checking the linkage to skill derivation and on-site execution.

## Criteria
It is determined as PASS when it is confirmed that common context has been made concrete into an executable structure fitting actual units of work, and the linkage to the following stage (skill derivation) is recorded.
