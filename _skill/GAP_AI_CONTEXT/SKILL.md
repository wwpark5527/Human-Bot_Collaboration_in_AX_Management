# AI Context Gap — Skill

## Purpose
Diagnose the AI context gap and convert context capital into a common production base of the organization.

## Input
- Materials on the organization's purpose, criteria, language, way of working, output formats, and verification criteria

## Procedure (Steps)
1. Explicitly document the organization's purpose, criteria, language, way of working, output formats, and verification criteria.
2. Expand across the organization the personnel and systems (context designers) able to provide these to AI.
3. Check the structure of ownership, access, verification, and outcome attribution of context capital.
4. Convert context capital into a common production base accessible to the whole organization and verify the results.

## Output
Materials documenting the organizational context and a context capital sharing system.

## Criteria
It is judged PASS when the capability to provide context is distributed across the organization, and FAIL when it is concentrated in a few.
