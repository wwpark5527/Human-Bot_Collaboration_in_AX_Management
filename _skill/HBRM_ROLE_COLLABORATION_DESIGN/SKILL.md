# Collaboration-Structure Design — Skill

## Purpose
Make the human-bot role and responsibility boundaries set in role design concrete as an actual collaboration flow so that humans and bots interlock and operate.

## Input
- The deliverables of the role-design stage (the role assignment table by type, the responsibility-boundary rules)
- An overview of the target work process

## Procedure (Steps)
1. Check the deliverables of the role-design stage.
2. Arrange the order of human-bot involvement for each unit of work along a time sequence.
3. Decide the work-handover points and the verification method.
4. Review and adjust the points where bottlenecks or conflicts may occur.
5. Document the completed collaboration flow and pass it on to the augmentation management stage.

## Output
Human-bot collaboration flow diagram, work handover and verification point definition document, collaboration-structure design document.

## Criteria
If the human-bot collaboration flow has been designed in a document including handover points and verification methods, it is judged PASS (collaboration-structure design complete); if the flow is not defined or the handover and verification points are unclear, it is judged FAIL (collaboration-structure design incomplete).
