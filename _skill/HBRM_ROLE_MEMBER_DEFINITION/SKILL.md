# Member Definition — Skill

## Purpose
Define the four member types of the AX organization (H, AH, B, AB) so that they have a clear position and role within the organization.

## Input
- The organization's current status of human/bot members
- An overview of the eight-role HBRM system

## Procedure (Steps)
1. Review the organization's current scope of members and confirm whether bots are actually performing work.
2. Classify members into the four types H, AH, B, and AB.
3. Decide the position each type will occupy within the organization (on a role basis).
4. Stipulate and document, at a first level, the role and responsibility boundaries of each type.
5. Connect the definition results to the subsequent role-design stage.

## Output
Member type definition document (H/AH/B/AB), rules on the position within the organization by type, draft of the role and responsibility scope by type.

## Criteria
If the position and role within the organization are explicitly defined for all four types H, AH, B, and AB, it is judged PASS (member definition complete); if even one is left undefined, it is judged FAIL (member definition incomplete).
