# Role Design — Skill

## Purpose
Set the role and responsibility boundaries among the member types H, AH, B, and AB in an AX organization, thereby making role-centered collaborative management possible.

## Input
- The deliverable of the member-definition stage (the definition of the positions and roles of H/AH/B/AB)
- An overview of the organization's work processes

## Procedure (Steps)
1. Check the deliverable of the member-definition stage.
2. List the concrete roles each type will carry out.
3. Set the responsibility boundaries between humans and bots for each role.
4. Document the established role and responsibility boundaries.
5. Pass the documentation results on to the collaboration-structure design stage.

## Output
Role assignment table by type, human-bot responsibility boundary rules, role design document.

## Criteria
If the role and responsibility boundaries between humans and bots are explicitly stated in a document, it is judged PASS (role design complete); if the boundaries are unclear or left undocumented, it is judged FAIL (role design incomplete).
