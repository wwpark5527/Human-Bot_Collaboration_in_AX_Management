# knowledge — Skill

## Purpose
It determines whether the 'knowledge' node of the knowledge-action chain actually organized data, information, and evidence into a connected structure of knowing, and whether it is in the state of a static basis for judgment that does not yet include execution and results.

## Input
- The raw data within the organization
- The list of related information and evidence

## Procedure (Steps)
1. Collect the data and organize it into information.
2. Systematize the information into knowledge.
3. Compose the connection relations among the knowledge.
4. Produce a basis-for-judgment structure that can answer "what do we know."

## Output
The basis for judgment (organizational knowledge as a static structure).

## Criteria
If data, information, and knowledge are connected so that "what do we know" can be answered, it is judged PASS; if the connections are broken, FAIL.
