# Execution model — Skill

## Purpose
Concretize the concepts theorized at the proposed-concept layer (inclusive AI-transition ESG, context access right, accountable operating system, and so on) into an operating model that can actually be run inside the organization.

## Input
- The theorization document of the proposed-concept layer (the list of newly proposed concepts)

## Procedure (Steps)
1. Review the theorized concepts.
2. Design the impact assessment procedure.
3. Build the authority design, verification, and approval procedures.
4. Prepare a recording system.
5. Design a performance-sharing system.
6. Build an improvement loop.

## Output
An organizational operating model that includes impact assessment, authority design, verification, approval, recording, performance sharing, and improvement loops (the execution model layer, operationalization).

## Criteria
It is judged PASS when all 7 constituent elements (from impact assessment through improvement loops) are concretized into executable procedures, and FAIL when one or more remain at the theoretical stage.
