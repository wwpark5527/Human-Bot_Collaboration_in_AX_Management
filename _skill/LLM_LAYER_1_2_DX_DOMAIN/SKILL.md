# Layers 1–2 (the domain of DX) — Skill

## Purpose
By the standard of the LLM architecture, determine whether the target organization's processing system lies in the domain of DX (layers 1–2).

## Input
- The target organization's data and information processing status
- The LLM architecture (the layer 1–4/5 structure)

## Procedure (Steps)
1. Distinguish whether the output of the target processing system is at the level of data and information or at the level of knowledge.
2. If it remains at the stage prior to knowledge-ization (data and information), classify it as layers 1–2 (the domain of DX).
3. If it has been converted to the level of knowledge, reclassify it as layer 3 or above.
4. Inspect the progress of forming layer 3 (the knowledge chain) and record the effect of strengthening layers 1–2.

## Output
The result of determining the domain of DX (layers 1–2), and a diagnostic report on the strengthening of layers 1–2 through linkage with layer 3.

## Criteria
It is judged PASS when the determination result accurately conforms to the standard of the architecture (data and information vs. knowledge).
