# Meaning design capability — Skill

## Purpose
By grasping the meaning elements related to the organization and its work and forming the relations among them, support humans in designing the vision, identity, and community meaning that AI cannot make, and in supporting problem framing.

## Input
- Background information related to the target organization and its work
- Candidate meaning elements that need to be grasped (vision, identity, community meaning, and so on)

## Procedure (Steps)
1. List and grasp the meaning elements related to the target.
2. Analyze the relations among meaning elements that are large and small, or of various types.
3. Structure the analyzed relations into a single meaning system.
4. Inspect whether the structured meaning system supports problem framing.

## Output
A list of grasped meaning elements and a meaning system structured by the relations among meanings.

## Criteria
It is judged PASS (meaning design capability secured) if one has grasped meaning and formed relations among meanings of various types so as to create a meaning system that supports problem framing, and FAIL (the meaning system needs to be redesigned) if grasping meaning or forming relations has failed.
