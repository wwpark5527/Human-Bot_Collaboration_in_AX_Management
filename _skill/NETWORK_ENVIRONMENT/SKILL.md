# Network environment — Skill

## Purpose
Inspect, at the whole-organization unit, the procedures for authority, security, verification, approval, recording, responsibility, and improvement by which multiple local work contexts are connected, verified, approved, recorded, held accountable, and improved, and judge whether the network operating context (governance context) is in place.

## Input
- A list of local environments (individual work contexts) within the organization
- Material defining authority, security, verification, approval, recording, responsibility, and improvement at the connection points between local work contexts

## Procedure (Steps)
1. Identify the multiple local environments within the organization.
2. Grasp the points at which local work contexts connect to each other.
3. Inspect whether authority, security, verification, approval, recording, responsibility, and improvement are managed at each connection point.
4. Mark undefined items as governance-context blanks.
5. Judge whether the network operating context is complete.

## Output
The judgment result on the operating network of the whole organization, that is, the network operating context.

## Criteria
It is judged PASS if authority, security, verification, approval, recording, responsibility, and improvement are all managed at the organizational level, and FAIL if even one of them is undefined.
