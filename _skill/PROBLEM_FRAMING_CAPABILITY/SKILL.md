# Problem Framing Capability — Skill

## Purpose
By reviewing candidate problems in a given situation and defining the essential problem and the direction that matters, it supports humans in leading the success of the AX organization as problem framers rather than answer generators.

## Input
- Background information on the situation or issue to be addressed
- A list of related candidate problems (where one exists)

## Procedure (Steps)
1. Review the situation and list the candidate problems.
2. Discriminate whether each candidate problem is essential.
3. Decide the direction that matters on the basis of the essential problem, and define the problem.
4. Share the defined problem with AI and the parties involved to align direction.

## Output
The result of judging the essential problem and the definition of the framed problem.

## Criteria
If one can settle on one's own which problem is to be solved, what is essential, and which direction matters, it is judged PASS (problem framer); if one cannot even define the problem on one's own, it is judged FAIL (remaining an answer generator, redefinition needed).
