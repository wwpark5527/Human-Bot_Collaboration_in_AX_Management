# Problem Definer — Skill

## Purpose
Because AI cannot understand a problem on its own in a way that fits the organization's context, this supports AX talent in first clearly defining the problem the organization has to solve before directing AI work.

## Input
- The work situation or issue to be solved
- Related work and performance goals

## Procedure (Steps)
1. Specify the object to be solved concretely and clarify what the problem is.
2. Reveal the grounds for why this problem is importantly connected to work and performance.
3. Set the standards for the required deliverable.
4. Check constraints such as security, cost, time, and legal conditions.
5. Set the success criteria (indicators) by which performance will be judged.

## Output
A problem definition in which the object to be solved has been clarified, together with deliverable and performance standards.

## Criteria
If all five items — what is the problem, why does it matter, what result is needed, what constraints exist, and what are the success criteria — have been clearly defined, it is judged PASS (problem definition complete); if even one is unclear, it is judged FAIL (problem definition needs supplementation).
