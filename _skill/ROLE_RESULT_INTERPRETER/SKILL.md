# Result Interpreter — Skill

## Purpose
Because an AI result cannot become the organization's judgment as it stands, this supports AX talent in interpreting the meaning of that result in the organizational context and converting it into an organizational judgment that can actually be used.

## Input
- The deliverable generated by AI
- The organization's work context to which the result will be applied

## Procedure (Steps)
1. Review whether the AI result fits our organization's situation.
2. Judge the validity of the core logic.
3. Check the executability of the result.
4. Inspect whether anything is missing.
5. Check whether there is any dangerous interpretation and organize it in a form usable in decision-making.

## Output
An interpretation of the meaning of the AI result, converted into organizational judgment.

## Criteria
If all six items — does it fit our organization's situation, is the core logic valid, is it executable, is anything missing, is there any dangerous interpretation, and can it be used in decision-making — are satisfied, it is judged PASS (convertible into organizational judgment); if even one is unsatisfied, it is judged FAIL (reinterpretation needed).
