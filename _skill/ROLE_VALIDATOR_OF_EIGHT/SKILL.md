# Validator — Skill

## Purpose
Because AI results are fast but not always accurate, this supports AX talent, as a quality manager of AI results, in checking results with defined verification criteria.

## Input
- The AI output requiring verification
- The organizational purpose and security criteria to which that output will be applied

## Procedure (Steps)
1. Check factuality — is there anything contrary to fact.
2. Check sourcing — is the grounding clear.
3. Check logic — does the reasoning connect from start to end.
4. Check completeness — is any important content missing.
5. Check suitability — does it fit the organization's purpose.
6. Check security — is any sensitive information included.
7. Check accountability — may it be reflected in the work.
8. Check traceability — are the judgment process and revision history kept.

## Output
A quality-check result that prevents dangerous automation.

## Criteria
It is judged PASS (quality check complete) when all eight items — factuality, sourcing, logic, completeness, suitability, security, accountability, and traceability — are satisfied, and FAIL (risk of dangerous automation, re-verification required) if even one is unsatisfied.
