# Self-perception inventory (SPI) — Skill

## Purpose
By accurately collecting the subjective self-perception of the person being measured through a survey-item response format, this provides the person's own response data for diagnosing an individual's TR type and level.

## Input
- Information on the person being measured
- The SPI survey item sheet

## Procedure (Steps)
1. Confirm the person being measured and distribute the SPI questionnaire.
2. Proceed so that the person responds directly to the survey items without the intervention of others.
3. Collect the responses and organize them into the Interplace input format.
4. Prepare to combine them with the observer assessment (OA) responses for the same person.
5. Combine the SPI (subjective) and OA (objective) responses and pass them on for mixed relative/absolute evaluation processing.

## Output
Raw SPI response data per individual, preliminary material for identifying TR type and level based on the person's own responses, and input data for combination with the OA.

## Criteria
It is judged PASS (a valid SPI response) when the response was written directly by the person being measured through a survey-item response format, and FAIL (cannot be recognized as an SPI) when it is a response by someone other than the person or is in a checklist format (the OA format).
