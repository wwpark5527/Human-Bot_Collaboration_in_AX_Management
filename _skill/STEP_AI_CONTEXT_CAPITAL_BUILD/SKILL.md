# 2. Build AI Context Capital — Skill

## Purpose
Organize purpose, criteria, sources, roles, formats, and verification standards for each task to build the context capital AI will use, and perform the second step of the AI Inclusive-Transformation ESG execution model (9 steps).

## Input
- The results of step 1, AI impact assessment, the task classification system and job descriptions, existing work manuals and standards documents, and the list of locations of reference materials

## Procedure (Steps)
1. Define the task units for which context capital will be built and set their priorities.
2. Organize the six items for each task — purpose, criteria, sources, roles, formats, verification standards.
3. Accumulate the organized context in a form AI can reference and provide access paths to it.
4. Calculate the per-task context-capital build rate and supplement the tasks not yet built.
5. Set a refresh cycle and update regularly, and reorganize the items that have passed the cycle.

## Output
Organized context capital — the list of task units, the organized set of the 6 items for each task, the accumulated body in a form AI can reference, and the measurement results of the build rate and the refresh cycle.

## Criteria
It is judged PASS if all six items are organized and accumulated for each task and the build rate and the refresh cycle are managed, and FAIL if items are missing or refreshing is neglected. (ESG linkage: S / G)
