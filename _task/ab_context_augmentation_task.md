# Context Augmentation — Task

## Tasks
1. Organize the organization's purpose, work standards, roles, and materials that the bot must access and use.
2. Connect these through the common context (the organizational AX OS) so that the bot can understand and use them.
3. Confirm whether the results of the bot's work reflect the organizational context.
4. Where the reflection of context is insufficient, supplement the scope of the context provided.

- A record of common context connections
- Results of the context-reflection confirmation
