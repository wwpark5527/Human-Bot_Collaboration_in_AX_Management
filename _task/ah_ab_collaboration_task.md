# Collaboration between Augmented Humans and Augmented Bots — Task

## Tasks
1. Build the common context by organizing the organization's purpose, work standards, reference materials, formats, and prohibitions.
2. Build the governance context by defining which bot can access which materials, which results require human approval, and which records must be kept.
3. The human performs the role of providing the bot with purpose and standards.
4. The bot performs the role of taking charge of analysis, execution, and recording and presenting structure and possibility to the human.
5. Accumulate the results of the collaboration (purpose, standards, materials, judgment, revision, approval, recording) as organizational assets reusable in the next task.

## Deliverables
- A common context document (purpose / work standards / reference materials / formats / prohibitions)
- A governance context system (access authority / approval procedures / recording rules)
- Role-based collaboration deliverables (reusable organizational assets)
