# Cognitive Augmentation (Cognitive A.) — Task

## Tasks
1. Comparatively measure the number of alternatives (options) generated for the same problem before and after the use of AI.
2. Comparatively measure the number of variables considered when making a judgment before and after the use of AI.
3. Measure the change in thinking depth (the degree to which a problem is analyzed from multiple angles) and cognitive speed (the time taken to reach a judgment).
4. Combine the three measures and reach a judgment on "Does AI broaden my range of thinking (cognition)?"

## Deliverables
- A comparison table of the number of alternatives generated
- A comparison table of the number of variables considered
- Measurement results for thinking depth / cognitive speed
