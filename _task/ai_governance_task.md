# AI Governance — Task

## Tasks
1. Organize the prohibition rules, accountability rules, audit system, and approval system needed for AI use as norms, institutions, and an operating system.
2. Distinguish governance context (the judgment-standard context) and AI governance (the system of control) as different levels and thereby prevent confusion.
3. Translate governance context into work procedures, roles, systems, and recording structures and reflect it in actual operation.
4. Check that control does not stop at prohibition, surveillance, and after-the-fact audit but becomes operation, standardization, and connected operation.

## Deliverables
- Definition document of the order of AI use (prohibition, accountability, audit, approval systems)
- Level distinction table for AI governance versus governance context
- Operating document translating governance context into work procedures, roles, systems, and recording structures
