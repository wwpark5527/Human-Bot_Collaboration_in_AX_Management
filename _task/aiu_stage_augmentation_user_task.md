# Augmentation User — Task

## Tasks
1. Measure the change in the member's decision quality before and after using AI.
2. Measure the change in the member's learning speed before and after using AI.
3. Measure the change in the member's productivity before and after using AI.
4. Combine the three indicators and judge "After using AI, have I become a different person from my earlier self?"
5. Register members judged to be Augmentation Users as subjects for the completion of AI Utilization (AIU) measurement and for the calculation of the Augmentation Quotient (AQ).

## Deliverables
- A measurement table of improved decision quality
- A measurement table of increased learning speed and productivity
- The Augmentation User stage judgment result
