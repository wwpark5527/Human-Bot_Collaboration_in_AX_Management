# Tool User — Task

## Tasks
1. Record the member's AI-usage frequency (number of uses per day/week).
2. Record the member's number of AI questions and the degree to which generated results are used.
3. Take "Could the same result be produced even without AI" as the evaluation question and make the determination.
4. Decide on the basis of the determination result whether the Tool User stage applies.
5. Register members determined to be Tool Users as targets for transition to Collaborative User.

## Deliverables
- Record table of AI-usage frequency and number of questions
- Indicator of the degree to which generated results are used
- Tool User stage determination result
