# Augmentation Quotient (AQ) — Task

## Tasks
1. Secure the member's AIU (AI Utilization) value.
2. Evaluate the degree of role-centered use (Role Alignment).
3. Evaluate the level of human-bot collaboration (Collaboration).
4. Evaluate the level of ethics/security/approval compliance (Governance).
5. Multiply the four elements (AIU, Role Alignment, Collaboration, Governance) to produce AQ.
6. Register the produced AQ as the input for calculating AHI (the Augmented Human Index).

## Deliverables
- Evaluation records of the four components AIU/Role Alignment/Collaboration/Governance
- An AQ calculation table (the result of applying the formula)
- The AQ value for input to the AHI calculation
