# Format — Task

## Tasks
1. List the types of outputs the organization produces (reports, proposals, training materials, record forms, etc.).
2. Define a standard structure (format) for each type and register it as a component of the common context.
3. Inspect whether current outputs are being made in a different format by each person, each department, and each tool.
4. Produce a standardized output structure that allows review, comparison, approval, and reuse.

## Deliverables
- A definition document of the standard format for each output type
- The results of inspecting the state of format inconsistency
- A document of the standardized output structure
