# Purpose — Task

## Tasks
1. Collect the reasons the organization uses AI by area of work (customer service, education, legal affairs, marketing, development, management reporting, etc.).
2. Organize the collected reasons in the organization's own language and settle them as a purpose statement.
3. Register the purpose statement as a component of the common context so that AI does not have to guess with every request.
4. Mark as a gap the areas of work for which no purpose is defined.

## Deliverables
- A list of AI-use purpose statements by area of work
- A document of the organization's own standard of purpose for using AI
- A list of gaps where purpose is undefined
