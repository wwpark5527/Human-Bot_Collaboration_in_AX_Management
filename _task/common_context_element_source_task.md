# Source — Task

## Tasks
1. Identify the kinds and sources of the grounding materials AI uses in producing outputs.
2. Define a procedure for confirming whether each source has been verified.
3. Build a record system through which the source, standards, revisions, and approval process can be traced after the fact.
4. Inspect cases in which unverified information was presented as if it were fact and mark the source confusion.

## Deliverables
- A list of the sources of grounding materials and their verification status
- A record system for tracking source, standards, revisions, and approval
- The results of inspecting cases of source confusion
