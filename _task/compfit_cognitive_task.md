# Cognitive complementation — Task

## Tasks
1. Divide cognitive decision-making tasks such as strategy meetings into the parts requiring intuition, creativity, and imagination and the parts requiring computation, search, and memory.
2. Assign the parts requiring computation, search, and memory (for example, data simulation) to the bot.
3. Assign the parts requiring intuition, creativity, and imagination (for example, interpreting the strategic meaning) to the human.
4. Document the collaboration procedure by which the human strategically interprets and judges the bot's output.

## Deliverables
- A cognitive task allocation table (human-assigned vs. bot-assigned)
- A collaboration procedure document linking the bot's data simulation output to the human's strategic interpretation result
