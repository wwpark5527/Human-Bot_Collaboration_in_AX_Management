# Contribution conflict — Task

## Tasks
1. Compare the criteria of side A and side B for the same message.
2. Confirm the difference in interpretation between side A and side B.
3. Confirm the difference between side A's and side B's judgment of the verification state (verified/unverified).
4. Confirm the difference in responsibility judgment as to whether it can be shared (shareable/security risk).
5. If a difference is found, define it as a contribution conflict and prepare an adjustment path.

## Deliverables
- The identification of contribution conflict — the definition of the conflict point that becomes important in AH-AH communication, superseding the role vacancy.
