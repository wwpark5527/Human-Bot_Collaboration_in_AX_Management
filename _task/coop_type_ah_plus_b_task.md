# AH + B (intelligent division of labor) — Task

## Tasks
1. Confirm whether the cooperation configuration within the organization consists of one augmented human (AH) and multiple non-augmented bots (B), and identify it as the AH + B type.
2. Clearly allocate to the human (AH) the role of formulating strategy and to the bots (B) the role of carrying out execution.
3. Build a multi-agent environment capable of directing multiple bots simultaneously.
4. Apply a human-in-the-loop design by which the human can intervene in and verify the bots' execution results.
5. Establish a role-based agent design that subdivides roles per bot.

- A multi-agent environment build plan, a human-in-the-loop design document, and a role-based agent design document
