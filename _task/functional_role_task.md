# Functional Role — Task

## Tasks
1. Confirm the formal job units that exist within the team (for example, recruiting officer, evaluation officer, payroll officer, benefits officer).
2. Confirm whether each job was formally assigned by the organization or a superior.
3. Determine whether each role is directly job-related.
4. Confirm the roles that meet both conditions as functional roles and list them.
5. Compare the list of functional roles with the list of team roles and review whether there is any overlap or confusion.
6. Register the completed list of functional roles as base material for TRB diagnosis.

## Deliverables
- A list of functional roles (job assignments) by team member
- A functional role–team role comparison table
- Base material on functional roles for TRB diagnosis
