# Accountability — Task

## Tasks
1. Identify the scope in which AI results are used and the person ultimately responsible for that use.
2. Define the criteria by which the responsibility for judgment is attributed (who, on what grounds, and how far).
3. Check the defined accountability system by mapping it to ISO/IEC 42001 (top-management responsibility), NIST (Govern), and the EU AI Act (provider and deployer obligations).
4. Register the accountability system as the accountability component of the governance context.

## Deliverables
- A definition document on the person ultimately responsible for use and the criteria of judgment
- An international-standard mapping checklist (ISO/IEC 42001, NIST, EU AI Act)
- A document on the system for clarifying where responsibility lies
