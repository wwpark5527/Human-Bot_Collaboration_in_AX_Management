# Improvement — Task

## Tasks
1. Identify cases of errors and failures that have arisen in the course of AI operation.
2. Define the location of the criteria (policies, prompts, verification checklists, and so on) into which errors and feedback should be reflected.
3. Check the defined improvement system by mapping it to ISO/IEC 42001 (continual improvement), NIST (Manage), and the EU AI Act (post-market monitoring).
4. Register the improvement system as the improvement component of the governance context and reflect it in the next cycle.

## Deliverables
- Definition document of error and failure cases and the criteria for reflecting them
- International standards mapping checklist (ISO/IEC 42001, NIST, EU AI Act)
- System document for organizational learning and improvement of criteria
