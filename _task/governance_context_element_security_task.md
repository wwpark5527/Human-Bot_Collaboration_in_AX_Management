# Security — Task

## Tasks
1. Identify, in each context within the organization, the information (sensitive information, confidential material) that must not be entered into, shared with, or generated by AI.
2. Define, per context, the handling criteria for the identified information (entry prohibited, sharing prohibited, generation prohibited).
3. Check the defined criteria by mapping them to ISO/IEC 42001 (data/asset management), NIST (Map/Manage), and the EU AI Act (data governance, Article 10).
4. Register the protection system for sensitive information and confidentiality as the security component of the governance context.

## Deliverables
- List of information prohibited from entry, sharing, and generation per context
- International standards mapping checklist (ISO/IEC 42001, NIST, EU AI Act)
- Protection system document for sensitive information and confidentiality
