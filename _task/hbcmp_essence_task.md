# Essence — Task

## Tasks
1. Collect the observed states of tension (human or bot).
2. Classify whether the tension in question arose in the psychological/emotional domain (human) or in the functional/computational domain (bot).
3. Apply whichever is appropriate, the human-stress response system or the bot-stress response system, according to the classification result.
4. Check that there are no cases of response in which the two stress domains have been confused.

## Deliverables
- Classification record of the domain of the state of tension (psychological/emotional or functional/computational)
- Results of applying the response system per domain
- Inspection report on cases of confusion
