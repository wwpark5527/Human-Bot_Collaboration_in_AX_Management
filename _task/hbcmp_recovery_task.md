# Recovery Method — Task

## Tasks
1. Confirm the human or bot cases determined to be in a state of stress.
2. If it is a human case, select and apply the appropriate prescription among rest, empathy, and motivation.
3. If it is a bot case, select and apply the appropriate prescription between readjustment (realignment) and relearning.
4. Re-confirm whether the state has improved after the prescription is applied.

## Deliverables
- A record of the application of the prescription type (human: rest/empathy/motivation, bot: readjustment/relearning)
- The result of confirming the improvement of the state after the prescription
