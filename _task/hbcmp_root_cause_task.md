# Root Cause — Task

## Tasks
1. Collect cases of subjects (human or bot) showing signs of stress.
2. If it is a human case, break down which factor among anxiety, relationships, or identity is the cause.
3. If it is a bot case, break down which factor among Overload, Conflict, or Misalignment is the cause.
4. Assign the case to the response system matching the identified family of cause (human-side vs system-side).

## Deliverables
- A classification record of the family of cause (human: anxiety/relationships/identity, bot: overload/conflict/misalignment)
- The result of assigning a response system per cause
