# AI's decision-making process must be recorded — Tasks

## Tasks
1. Design a recording form for the four items that must be recorded (grounds of judgment, data used, approver, risks reviewed) for each type of judgment in which AI is involved.
2. Connect an automatic recording (logging) function to the AI judgment system or workflow so that records are made without omission.
3. Define the authority and procedures for accessing, retrieving, and auditing the records.
4. Periodically examine and correct cases where a record was missing or incomplete.

## Deliverables
- A standard form for AI judgment records (the four items of grounds, data, approver, risks)
- An automatic logging system for AI judgments and a procedure document for access and audit
- A report examining cases of missing or incomplete records
