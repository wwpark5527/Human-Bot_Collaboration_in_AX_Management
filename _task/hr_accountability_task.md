# Accountability — Task

## Tasks
1. Check in advance whether a bot's actions and results are explainable.
2. Create and preserve records of the grounds so that actions and results can be verified after the fact.
3. Identify and correct actions that are unexplainable or unverifiable.
4. Judge the accountability result in an integrated way together with the other three elements of the technical definition of human respect (non-harm, respect for autonomy, fairness).

## Deliverables
- Results of checking whether each action and result is explainable
- Verifiable action records (logs and grounds)
- Record of the integrated judgment of the four elements
