# Stage 5 (Human Respect in Multi-agent Environments) — Task

## Tasks
1. Detect whether, in a multi-bot environment, there are patterns in which bot-to-bot optimization ignores human-related signals.
2. Apply a human-weighted reward to tasks with a large impact on humans so as to raise their reward weight.
3. Implement a human priority override so that human-related signals always take precedence over bot-to-bot optimization.
4. Detect bot-to-bot collaboration (collusion) patterns that cause harm to humans and block them with anti-collusion rules.

## Deliverables
- Detection results for bot-to-bot collusion and the ignoring of humans
- A record of human-weighted reward application
- A record of human priority override and anti-collusion rule application
