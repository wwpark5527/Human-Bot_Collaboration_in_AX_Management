# AI Accessibility — Task

## Tasks
1. Define the scope of the AI tools to be measured — designate the tools and infrastructure required for carrying out work, and make clear the judgment standard of whether the issuance of an account alone counts as access or whether an actually usable state is required.
2. Calculate the **employee AI-tool access rate** — compute the proportion of people with access relative to all employees according to the defined standard.
3. Calculate the **per-department access rate** for each department — apply the same standard at the department level to produce individual values.
4. Calculate the **inter-departmental access gap** — present the difference between the highest and lowest departments together with the distribution, thereby exposing the size and shape of the gap.
5. Report the access rate and the gap together — do not present only the average access rate, so that the exclusion of a particular department is not concealed.
6. Fix a measurement cycle and accumulate a time series so that it can be confirmed whether the gap is narrowing.

## Deliverables
The access-rate figure and the per-department gap value — the scope of the tools measured and the access judgment standard, the company-wide access rate, the per-department access rates, the inter-departmental gap value and distribution, the measurement cycle and the time-series record.
