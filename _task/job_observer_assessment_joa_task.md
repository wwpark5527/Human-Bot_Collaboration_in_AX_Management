# Job Observer Assessment (JOA: job observer assessment) — Task

## Tasks
1. Fix the job to be diagnosed (the same job unit as JRE).
2. Select job observers who can observe that job.
3. Guide the job observers to respond on the basis of the observation results (job-observation items) (on the basis of observation results, not a description of requirements).
4. Organize the collected job-observation data into the Interplace input format.
5. Combine the JOA data with the job requirement exercise (JRE) data and pass it on as input to job assessment.

## Deliverables
- The raw JOA response data by job
- The job-observation data
- The input data for combination with JRE (job assessment material)
