# Job Requirement Exercise (JRE: job requirement exercise) — Task

## Tasks
1. Fix the job to be diagnosed (the job, not a person, is the unit of assessment).
2. Distribute the JRE to respondents who are well versed in that job (job holders, managers, and the like).
3. Instruct them to respond on the basis of the requirements that the job demands (job-requirements items).
4. Organize the collected job-requirements data into the Interplace input format.
5. Hand over the JRE data so that it can be combined with the Job Observer Assessment (JOA) data.

## Deliverables
- Raw JRE response data per job
- Job-requirements data
- Input data for combination with the JOA (job-assessment material)
