# Premise-Relation Measurement — Task

## Tasks
1. Grasp the advanced concept (expression) to be checked and the lower concept that underlies it.
2. Check the connection state between the higher concept and the lower concept.
3. Detect whether there are cases of speaking about the advanced concept without having understood the foundational concept.
4. When a foundational-concept deficiency is found, judge it as "a state where the words are advanced but the foundational concept is weak."
5. Organize the judgment result so that it can be linked with the next function of the knowledge chain (reasoning-chain fidelity measurement).

## Deliverables
- The check result on the higher-lower concept connection state
- Whether a foundational-concept deficiency was found
- The judgment result of "a state where the words are advanced but the foundational concept is weak"
