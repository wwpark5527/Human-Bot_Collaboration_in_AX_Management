# Structural-Distance Measurement — Task

## Tasks
1. Grasp the current concept structure and the target structure respectively.
2. Compare the two structures and confirm missing concepts, incorrect connections, and unnecessary connections.
3. Calculate the structural distance in a way where the more missing concepts, incorrect connections, and unnecessary connections there are, the greater the distance.
4. Identify missing concepts and misconceptions from the calculated structural distance.
5. Organize the structural-distance value and the identification results so that they can be linked with the next function of the knowledge chain (premise-relation measurement).

## Deliverables
- The list of missing concepts, incorrect connections, and unnecessary connections
- The structural-distance value
- The identification result of missing concepts and misconceptions
