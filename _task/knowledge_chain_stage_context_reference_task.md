# Organizational Context Reference — Task

## Tasks
1. Map the request unit passed on from the question stage onto the organization's common context (purpose, standards, roles, sources, format).
2. Bring in the parts of the organization's history, intent, norms, and memory that are related to that question.
3. Compose the interpretation context by referencing the organization's standards, so that per-user differences in interpretation do not intervene.
4. Pass the composed interpretation context on to the next stage (governance validation).

## Deliverables
- The question interpretation mapped onto the organization's common context
- An interpretation context document in which organizational standards are reflected
- The interpretation context passed on to the next stage (governance validation)
