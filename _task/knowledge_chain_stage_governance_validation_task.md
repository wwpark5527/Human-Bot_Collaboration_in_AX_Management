# Governance Validation — Task

## Tasks
1. Confirm the interpretation context passed on from the organizational context reference stage and the response candidate to be generated.
2. Check whether that context and response candidate pass the organization's authority, security, verification, and approval standards (the 4 elements of the governance context).
3. Record the validation result and the locus of accountability so that they can be traced.
4. Pass on to the next stage (response generation) only the response candidates that have passed validation, and block those that have not.

## Deliverables
- A checklist comparing against the authority, security, verification, and approval standards
- A record of the pass/block judgment of validation (accountability traceable)
- The validated response candidate passed on to the next stage (response generation)
