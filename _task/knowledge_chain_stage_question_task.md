# Question — Task

## Tasks
1. Receive into the question stage the request that a human or an AI poses to the organization.
2. Confirm whether that question is consumed one-off and ends, or continues on to the next stage (organizational context reference).
3. Structure the question into a request unit that is passed on to the subsequent stage, and deliver it.
4. Check whether the question, as the entry stage of the knowledge chain, has been incorporated into the circulation/accumulation structure.

## Deliverables
- The question structured as a request unit
- A record of the judgment on the question's one-off/continuous character
- The request unit passed on to the next stage (organizational context reference)
