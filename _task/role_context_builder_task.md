# Context Builder — Tasks

## Tasks
1. Define the work purpose (why is this task done) and the target user (for whom is the deliverable).
2. State explicitly the organizational standards to be followed.
3. Determine the data scope that may be used and the prohibited conditions.
4. Set the deliverable format and the verification standards.
5. Determine the performance standards that the result must lead to.

## Deliverables
- A definition document of the work purpose and target user
- A list of organizational standards, data scope, and prohibited conditions
- A context specification including the deliverable format, verification standards, and performance standards
