# Problem Definer — Tasks

## Tasks
1. Specify the object to be solved concretely and clarify what the problem is.
2. Reveal the grounds for how this problem relates to work and performance.
3. Set the standards for the required deliverable.
4. Check constraints such as security, cost, time, and legal conditions.
5. Set the success criteria (indicators) by which performance will be judged.

## Deliverables
- A problem definition statement in which the object to be solved has been clarified
- A list of deliverable standards and constraints
- Success criteria (indicators) for judging performance
