# Validator — Task

## Tasks
1. Check that there is nothing contrary to fact (factuality).
2. Check that the grounding is clear (sourcing).
3. Check that the reasoning connects from start to end (logic).
4. Check that no important content is missing (completeness).
5. Check that it fits the organization's purpose (suitability).
6. Check that no sensitive information is included (security).
7. Check whether it may be reflected in the work (accountability).
8. Ensure that the judgment process and revision history are kept (traceability).
