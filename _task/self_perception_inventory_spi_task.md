# Self-perception inventory (SPI) — Task

## Tasks
1. Confirm the person being measured and distribute the self-perception inventory (SPI).
2. Guide the person to respond directly to the survey items.
3. Collect the person's subjective responses without omission.
4. Organize the collected responses into the Interplace system input format.
5. Pass on the SPI responses so that they can be combined with the observer assessment (OA) responses.

## Deliverables
- Raw SPI response data per individual
- Preliminary material for identifying TR type and level based on the person's own responses
- Input data for combination with the OA
