# 2. Build AI Context Capital — Task

## Tasks
1. Take the results of step 1, AI impact assessment, as input, define the task units for which context capital will be built, and set their priorities.
2. Organize the **purpose** of each task — state what that task is meant to achieve.
3. Organize the **criteria** of each task — state by what judgment criteria the good and the bad of the result are distinguished.
4. Organize the **sources** of each task — state the materials AI must reference and where they are located.
5. Organize the **roles** of each task — state who performs what and is accountable.
6. Organize the **formats** of each task — state what form the output must take.
7. Organize the **verification standards** of each task — state how it is checked that the result is correct.
8. Accumulate the six organized items in a form AI can reference, and measure and manage the build rate and the refresh cycle.

## Deliverables
Organized context capital — the list of task units and their priorities, the organized set of purpose, criteria, sources, roles, formats, and verification standards for each task, the accumulated body in a form AI can reference, and the measurement results of the per-task context-capital build rate and the refresh cycle.
